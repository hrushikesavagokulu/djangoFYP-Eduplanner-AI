Tuples - DevHive

Tuples are immutable ordered collections in some programming languages like Python. This means once created, their elements cannot be changed, added, or removed. However, JavaScript does not have built-in tuple types. Instead, you can use arrays to store ordered collections, but these arrays are mutable.

Tuple Declaration (Simulated in JavaScript)

In JavaScript, arrays are often used to mimic tuples:

const tuple = [1, 'apple', true];

This array contains different types of elements, which is similar to tuples in languages that support them.

Accessing Tuple Elements

console.log(tuple[0]);  // 1
console.log(tuple[1]);  // 'apple'
console.log(tuple[2]);  // true

Immutability: A Key Difference

Unlike tuples in Python, arrays in JavaScript are mutable. You can change elements after creation: 

tuple[1] = 'orange';
console.log(tuple);  // [1, 'orange', true]

This mutability means JavaScript arrays are not strict tuples but flexible collections.
