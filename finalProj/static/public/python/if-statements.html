Python if else Statement

Welcome to DEVHive! This tutorial covers everything you need to know about the if else statements in Python — the backbone of decision-making in your programs.

1. What is an if else Statement?

The if else statement allows your program to choose between two paths based on a condition. If the condition is true, it executes one block of code; otherwise, it executes another.

2. Syntax

if condition:
    # code runs if condition is True
else:
    # code runs if condition is False

3. How Does It Work?

The condition is a boolean expression evaluated to either True or False. Examples include:

  • age >= 18 (is age at least 18?)
  • score < 50
  • is_logged_in == True

Python uses indentation (spaces or tabs) to define which code belongs inside the if or else blocks — be sure to indent consistently!

4. Basic Example

age = 20
if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")

Output:

You are an adult.

5. Using elif for Multiple Conditions

Use elif (short for "else if") to test additional conditions: 

score = 85
if score >= 90:
    print("Grade A")
elif score >= 70:
    print("Grade B")
elif score >= 50:
    print("Grade C")
else:
    print("Fail")

Python checks conditions from top to bottom and runs the first true block.

6. Important Notes & Best Practices

  • Indent your blocks properly. Python requires consistent indentation (usually 4 spaces).
  • The condition must evaluate to True or False.
  • Use == to compare values (not =, which assigns).
  • You can have multiple elif blocks, but only one else block at the end.

7. Common Mistakes

  • Using a single equal sign = instead of == in conditions
  • Forgetting to indent code inside blocks
  • Using colon : after if, elif, and else statements
  • Not having an else block when needed

8. Nested if else

You can nest if else inside others to check more detailed conditions: 

num = 10
if num > 0:
    if num % 2 == 0:
        print("Positive even number")
    else:
        print("Positive odd number")
else:
    print("Zero or negative number")

9. Practical Examples

Example: User Login Check

is_logged_in = True
if is_logged_in:
    print("Welcome back!")
else:
    print("Please log in to continue.")

Example: Checking Temperature

temp = 25
if temp > 30:
    print("It's hot outside.")
elif temp >= 20:
    print("Nice weather!")
else:
    print("It's chilly.")
Tip: Use the bool() function to convert values to True/False in complex conditions!
