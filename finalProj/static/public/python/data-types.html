Python Basics Tutorial

Python Data Types

A data type defines what kind of data can be stored in a variable and what operations can be performed on it.

Python has several built-in data types, including:

Category Data Types
Text Typestr
Numeric Typesint, float, complex
Sequence Typeslist, tuple, range
Mapping Typedict
Set Typesset, frozenset
Boolean Typebool
Binary Typesbytes, bytearray, memoryview
None TypeNoneType

Getting the Data Type

Use the type() function to find out the data type of a variable:

x = 5
print(type(x))  # Output: <class 'int'>

Setting the Data Type Automatically

Python assigns the data type automatically based on the value:

x = "Hello World"       # str
x = 20                   # int
x = 20.5                 # float
x = 1j                   # complex
x = ["apple", "banana"]  # list
x = ("apple", "banana")  # tuple
x = range(6)             # range
x = {"name": "John"}     # dict
x = {"apple", "banana"}  # set
x = frozenset({"apple", "banana"})  # frozenset
x = True                 # bool
x = b"Hello"             # bytes
x = bytearray(5)         # bytearray
x = memoryview(bytes(5)) # memoryview
x = None                 # NoneType

Explicitly Specifying Data Types

You can also explicitly convert or specify data types using constructors:

x = str("Hello World")
x = int(20)
x = float(20.5)
x = complex(1j)
x = list(("apple", "banana"))
x = tuple(("apple", "banana"))
x = range(6)
x = dict(name="John", age=36)
x = set(("apple", "banana"))
x = frozenset(("apple", "banana"))
x = bool(5)
x = bytes(5)
x = bytearray(5)
x = memoryview(bytes(5))

Python Numbers

Python supports three numeric types:

  • int — Integer numbers (whole numbers without decimals)
  • float — Floating-point numbers (numbers with decimals)
  • complex — Complex numbers with real and imaginary parts

Example:

x = 1       # int
y = 2.8     # float
z = 1j      # complex

print(type(x))  # <class 'int'>
print(type(y))  # <class 'float'>
print(type(z))  # <class 'complex'>

Python Strings

Strings are sequences of characters, enclosed in single, double, or triple quotes.

Example:

txt = "Hello, World!"
print(txt)
print(type(txt))

Python Lists

Lists are ordered, mutable collections of items, enclosed in square brackets.

Example:

thislist = ["apple", "banana", "cherry"]
print(thislist)
print(type(thislist))
