Method Overriding - DevHive

Method overriding allows a subclass to provide a specific implementation of a method that is already defined in its superclass. This enables polymorphism where the child class behavior can replace or extend the parent class behavior.

Why Use Method Overriding?

  • To modify or extend the behavior of inherited methods.
  • To achieve runtime polymorphism.
  • To provide specific behavior for subclass objects.

Example in JavaScript

class Animal {
  speak() {
    console.log("Animal speaks");
  }
}

class Dog extends Animal {
  speak() {
    console.log("Dog barks");
  }
}

const d = new Dog();
d.speak();  // Dog barks

How It Works

When the speak() method is called on a Dog instance, the overridden method in the Dog class is executed instead of the method in Animal. This is because the child class's method has the same name and signature.

Calling the Parent Method

You can still call the parent class method inside the child method using super keyword:

class Dog extends Animal {
  speak() {
    super.speak();
    console.log("Dog barks");
  }
}

const d = new Dog();
d.speak(); 
// Output:
// Animal speaks
// Dog barks

Method Overriding vs Method Overloading

  • Overriding: Same method name and parameters in child and parent class, changes behavior.
  • Overloading: Multiple methods with same name but different parameters (not directly supported in JavaScript).

Real-world Use Case

In a GUI application, you might have a generic draw() method in a parent Shape class, and each shape subclass like Circle or Rectangle overrides it to draw themselves differently.
