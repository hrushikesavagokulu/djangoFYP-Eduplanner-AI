Built-in Modules in Python - DevHive

Python includes many built-in modules that provide useful functions and utilities. You can use them by importing the module.

Popular Built-in Modules

  • math – provides mathematical functions like sqrt(), sin(), etc.
  • random – generates random numbers and choices
  • datetime – works with dates and times
  • os – interacts with the operating system
  • sys – system-specific parameters and functions

Example Usage

import math
import random
import datetime

print("Square root of 16 is:", math.sqrt(16))
print("Random number between 1 and 10:", random.randint(1, 10))
print("Current date and time:", datetime.datetime.now())
