Method Overloading in Python - DevHive

Method overloading means defining multiple methods with the same name but different parameters. However, Python does not support traditional method overloading like Java or C++. Instead, Python uses default arguments, variable arguments, or type checking inside a single method to mimic overloading.

How Python Handles Overloading

Python uses flexible parameters rather than traditional overloading.

Example 1: Using Default Arguments

class MathOps:
    def add(self, a, b, c=0):
        return a + b + c

obj = MathOps()
print(obj.add(5, 10))      # 15
print(obj.add(5, 10, 20))  # 35

Example 2: Using *args for Variable Number of Arguments

class Calculator:
    def multiply(self, *args):
        result = 1
        for num in args:
            result *= num
        return result

calc = Calculator()
print(calc.multiply(2, 3))       # 6
print(calc.multiply(2, 3, 4))    # 24

Example 3: Overloading by Type Checking

class Printer:
    def display(self, data):
        if isinstance(data, int):
            print(f"Integer: {data}")
        elif isinstance(data, str):
            print(f"String: {data}")
        else:
            print("Unsupported type")

p = Printer()
p.display(100)        # Integer: 100
p.display("Hello")    # String: Hello
p.display(3.14)       # Unsupported type
