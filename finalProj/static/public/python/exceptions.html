Exception Handling - DevHive (Python)

Python's exception handling allows developers to deal with unexpected runtime errors in a clean and manageable way.

✨ Why Use Exception Handling?

  • Prevent your program from crashing unexpectedly.
  • Handle specific types of errors differently.
  • Run cleanup code regardless of success or failure.

🔧 Basic Syntax

try:
    # Code that might raise an error
except SomeSpecificError as e:
    # Handle the error
finally:
    # Optional block, always runs

🧪 Example: Divide by Zero

try:
    result = 10 / 0
    print(result)
except ZeroDivisionError:
    print("❌ Cannot divide by zero!")
finally:
    print("✅ Done executing!")

🔍 Common Exceptions

  • ZeroDivisionError - Division by 0
  • ValueError - Wrong value (e.g. letters instead of numbers)
  • TypeError - Incompatible types (e.g. adding string + int)
  • NameError - Variable not defined
  • IndexError - List index out of range
