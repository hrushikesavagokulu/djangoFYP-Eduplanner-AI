Indentation in Python

Indentation defines blocks of code. Unlike many languages where indentation is optional, in Python it must be consistent and is required for syntax correctness.

Correct example:

if 5 > 2:
    print("Five is greater than two!")

Incorrect example (causes IndentationError):

if 5 > 2:
print("Five is greater than two!")

Use consistent spaces (typically 4 spaces per level). Mixing tabs and spaces will also cause errors.

Comments

Use # for single-line comments:

# This is a comment
print("Hello!") # This is also a comment

For multi-line comments or docstrings, use triple quotes:

"""
This is a multi-line comment or docstring
used for explanations.
"""

Keywords

Python keywords are reserved words that cannot be used as variable names. Examples include:

if, else, elif, while, for, break, continue, def, return, class, try, except, finally, import, from, as, pass, yield, with, lambda, global, nonlocal, assert, raise, True, False, None

Indentation Error Example

def greet():
print("Hello")  # IndentationError because no indent inside function

Fix:

def greet():
    print("Hello")
