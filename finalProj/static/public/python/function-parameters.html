Function Parameters - DevHive

Function parameters allow you to pass values into functions so they can perform tasks with different inputs.

Types of Parameters in Python

  • Positional parameters: Passed in order and matched positionally.
  • Keyword parameters: Passed by explicitly naming the parameter.
  • Default parameters: Have default values if no argument is passed.
  • Variable-length parameters: Use *args for extra positional arguments and **kwargs for extra keyword arguments.

Examples

def greet(name, age):
    print(f"Hello {name}, you are {age} years old.")

def greet_default(name, age=18):
    print(f"Hello {name}, you are {age} years old.")

def sum_all(*args):
    print("Sum is:", sum(args))

def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

# Calling functions:
greet("Alice", 30)            # Positional
greet(age=25, name="Bob")     # Keyword
greet_default("Charlie")      # Uses default age = 18
sum_all(1, 2, 3, 4)           # Variable positional arguments
print_info(name="Diana", age=40, city="NY")  # Variable keyword arguments
