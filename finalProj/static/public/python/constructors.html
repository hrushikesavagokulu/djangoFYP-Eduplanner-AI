Constructor - DevHive

A constructor is a special method used to initialize objects created from a class.

Example

class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  greet() {
    console.log(`Hello, I'm ${this.name}, age ${this.age}`);
  }
}

const p1 = new Person("Dev", 22);
p1.greet();
