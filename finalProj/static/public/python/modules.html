Modules in Python - DevHive

A module in Python is a file containing Python code (functions, classes, variables) that can be imported and reused in other Python programs.

Why Use Modules?

Modules help organize code, avoid repetition, and promote modular programming by splitting code into separate files.

Importing Modules

# Import entire module
import math
print(math.sqrt(16))

# Import specific function
from math import pi
print(pi)

Creating Your Own Module

Save reusable functions or variables in a file, e.g. mymodule.py, then import it.

# mymodule.py
def greet(name):
    return f"Hello, {name}!"

# main.py
import mymodule
print(mymodule.greet("DevHive"))
