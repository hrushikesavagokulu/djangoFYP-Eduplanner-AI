Encapsulation - DevHive

Encapsulation is the concept of restricting direct access to some components of an object to protect its data.

Example

class Person {
  #name;

  constructor(name) {
    this.#name = name;
  }

  getName() {
    return this.#name;
  }

  setName(name) {
    this.#name = name;
  }
}

const p = new Person("Dev");
console.log(p.getName());
p.setName("Hive");
console.log(p.getName());
