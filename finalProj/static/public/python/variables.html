Python Variables - DevHive

Variables in Python are containers for storing data values. You do not need to declare their type explicitly because Python figures it out automatically.

Creating Variables

You can assign values to variables directly:

x = 5          # Assigns the integer 5 to x
y = "John"     # Assigns the string "John" to y
print(x)       # Outputs: 5
print(y)       # Outputs: John

Variable Types and Casting

Variables can change types, and you can also cast them explicitly:

x = 4           # x is of type int
x = "Sally"     # x is now of type str (changed)
print(x)        # Outputs: Sally

x = str(3)      # Casts integer 3 to string '3'
y = int(3)      # Keeps as integer
z = float(3)    # Casts to float 3.0

Get Variable Type

Use type() to get the type of a variable:

x = 5
y = "John"
print(type(x))  # Outputs: <class 'int'>
print(type(y))  # Outputs: <class 'str'>

String Quotes and Case Sensitivity

You can use single or double quotes for strings. Python variables are case-sensitive:

x = "John"
x = 'John'  # Same result as above
a = 4
A = "Sally"  # a and A are two different variables

Variable Naming Rules

Some variable names are valid, and some are not:

# Legal:
myvar = "John"
my_var = "John"
_my_var = "John"
myVar = "John"
MYVAR = "John"
myvar2 = "John"

# Illegal:
# 2myvar = "John"   → Cannot start with a number
# my-var = "John"   → Hyphen not allowed
# my var = "John"   → Spaces not allowed

Multiple Assignments

Assign values to multiple variables in one line, or same value to all:

x, y, z = "Orange", "Banana", "Cherry"
print(x)  # Outputs: Orange
print(y)  # Outputs: Banana
print(z)  # Outputs: Cherry

x = y = z = "Orange"
print(x)  # Outputs: Orange
print(y)  # Outputs: Orange
print(z)  # Outputs: Orange

Unpacking a Collection

Unpack a list of values into individual variables:

fruits = ["apple", "banana", "cherry"]
x, y, z = fruits
print(x)  # Outputs: apple
print(y)  # Outputs: banana
print(z)  # Outputs: cherry

Output Variables

You can print variables using commas or string concatenation:

x = "Python"
y = "is"
z = "awesome"
print(x, y, z)                  # Outputs: Python is awesome
print(x + " " + y + " " + z)    # Same as above

Global Variables

Variables created outside functions are global:

x = "awesome"

def myfunc():
  print("Python is " + x)

myfunc()  # Outputs: Python is awesome

If a variable with same name is created inside function, it becomes local:

x = "awesome"

def myfunc():
  x = "fantastic"
  print("Python is " + x)

myfunc()              # Outputs: Python is fantastic
print("Python is " + x)  # Outputs: Python is awesome

Global Keyword

Use global to make a local variable refer to the global scope:

def myfunc():
  global x
  x = "fantastic"

myfunc()
print("Python is " + x)  # Outputs: Python is fantastic
