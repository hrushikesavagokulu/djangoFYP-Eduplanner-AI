Loop Control - DevHive

Loop control statements allow you to change the normal flow of loops. They provide extra control over when to exit a loop or skip certain iterations. The two most commonly used loop control statements in JavaScript are break and continue.

Break Statement

The break statement immediately terminates the entire loop when encountered. Execution continues with the statement immediately following the loop.

Example:

for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    break;   // Loop stops entirely when i is 3
  }
  console.log(i);
}
// Output: 1 2

Explanation: The loop starts with i = 1, logs it, then increments. When i reaches 3, the break statement stops the loop entirely, so 3, 4, and 5 are not printed.

Continue Statement

The continue statement skips the rest of the current iteration and immediately starts the next iteration of the loop.

Example:

for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue;  // Skip just this iteration when i is 3
  }
  console.log(i);
}
// Output: 1 2 4 5

Explanation: When i is 3, the continue causes the loop to skip the console.log for that iteration and jump to the next iteration, so 3 is not printed.

Summary

  • break: Completely exits the loop immediately.
  • continue: Skips the rest of current loop iteration and continues with the next.
