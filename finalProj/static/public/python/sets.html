Sets - DevHive

Sets are collections of unique values. Duplicate values are automatically removed.

Creating a Set

const numbers = new Set([1, 2, 3, 2, 1]);
console.log(numbers); // Set(3) {1, 2, 3}

Set Methods

numbers.add(4);    // Add element
numbers.delete(2);  // Remove element
numbers.has(1);     // Check presence
numbers.size;       // Get size

Iterating over a Set

for (const value of numbers) {
  console.log(value);
}

Converting Set to Array

You can convert a Set to an Array using the spread operator or Array.from():

const arr = [...numbers];
const arr2 = Array.from(numbers);
console.log(arr, arr2);

Common Use Cases

  • Removing duplicate values from arrays
  • Checking existence of elements efficiently
  • Performing set operations like union, intersection (using custom code)

Example: Removing duplicates

const names = ['Alice', 'Bob', 'Alice', 'Eve'];
const uniqueNames = new Set(names);
console.log(uniqueNames); // Set(3) {'Alice', 'Bob', 'Eve'}

Example: Union of two sets

const setA = new Set([1, 2, 3]);
const setB = new Set([3, 4, 5]);
const union = new Set([...setA, ...setB]);
console.log(union); // Set(5) {1, 2, 3, 4, 5}

Example: Intersection of two sets

const intersection = new Set([...setA].filter(x => setB.has(x)));
console.log(intersection); // Set(1) {3}

Example: Difference of two sets

const difference = new Set([...setA].filter(x => !setB.has(x)));
console.log(difference); // Set(2) {1, 2}
