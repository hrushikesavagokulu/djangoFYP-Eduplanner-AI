Advanced Function Parameters in Python - DevHive

In Python, functions support powerful parameter definitions and combinations. By using default values, variable arguments, keyword-only arguments, unpacking, and decorators, you can write highly flexible and reusable code.

1. Default Parameters

If an argument is not passed to the function, the default value is used instead.

def greet(name, age=18):
    print(f"Hello {name}, you are {age} years old.")

greet("Alice")
greet("Bob", 25)
  • Default values are evaluated only once, when the function is defined.
  • Be cautious using mutable default arguments like lists or dicts.
Warning: Avoid mutable default arguments.
def append_end(lst=[]):
    lst.append("END")
    return lst

print(append_end())  # ['END']
print(append_end())  # ['END', 'END'] ❌

2. Variable Positional Arguments (*args)

Accepts any number of extra positional arguments as a tuple.

def add(*args):
    print("Args:", args)
    print("Total:", sum(args))

add(1, 2, 3, 4)

3. Variable Keyword Arguments (**kwargs)

Accepts any number of extra keyword arguments as a dictionary.

def info(**kwargs):
    for k, v in kwargs.items():
        print(f"{k}: {v}")

info(name="John", age=30)

4. Unpacking with * and **

def demo(a, b, c):
    print(a, b, c)

t = (1, 2, 3)
d = {'a': 10, 'b': 20, 'c': 30}

demo(*t)
demo(**d)

5. Full Parameter Order

  • Positional parameters
  • Default parameters
  • *args (variable positional)
  • Keyword-only parameters (after a lone *)
  • **kwargs (variable keyword)
def full_demo(a, b=10, *args, d, e=20, **kwargs):
    print(a, b, args, d, e, kwargs)

6. Keyword-Only Parameters

Parameters after a lone * must be passed as keyword arguments.

def person(name, *, age, city):
    print(f"{name} is {age} years old and lives in {city}.")

person("Alice", age=25, city="Delhi")

7. Lambda Functions with *args and **kwargs

func = lambda *args, **kwargs: (args, kwargs)
print(func(1, 2, x=3))

8. Decorators with *args and **kwargs

def logger(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__} with args {args} and kwargs {kwargs}")
        return func(*args, **kwargs)
    return wrapper

@logger
def greet(name, age=18):
    print(f"Hi {name}, age {age}")

greet("John", age=22)
