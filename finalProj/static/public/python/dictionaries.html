Dictionaries (Objects) - DevHive

In JavaScript, objects are used as dictionaries to store key-value pairs.

Creating an Object

const student = {
  name: "Dev",
  age: 21,
  course: "B.Tech"
};

Accessing & Modifying

console.log(student.name);  // Dev
student.age = 22;
console.log(student.age);

Looping through Object

for (let key in student) {
  console.log(key + ": " + student[key]);
}
