Comprehensions in Python - DevHive

Comprehensions provide a concise way to create lists, dictionaries, sets, or generators from iterable objects.

List Comprehensions

Create lists in a single readable line instead of loops.

# Example: List of squares from 1 to 5
squares = [x**2 for x in range(1, 6)]
print(squares)
# Output: [1, 4, 9, 16, 25]

Dictionary Comprehensions

Create dictionaries with key-value pairs.

# Example: Numbers and their squares
square_dict = {x: x**2 for x in range(1, 6)}
print(square_dict)
# Output: {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

Set Comprehensions

Create sets without duplicates.

# Example: Set of even numbers
even_set = {x for x in range(10) if x % 2 == 0}
print(even_set)
# Output: {0, 2, 4, 6, 8}

Generator Expressions

Generate items one by one without storing whole list in memory.

# Example: Generator of squares
gen = (x**2 for x in range(5))
for val in gen:
    print(val)
