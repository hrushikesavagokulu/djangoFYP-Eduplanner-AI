Recursion - DevHive

Recursion is a technique where a function calls itself to solve smaller instances of the same problem until a base condition is met.

Example: Factorial

function factorial(n) {
  if (n === 0) return 1;
  return n * factorial(n - 1);
}

console.log(factorial(5)); // 120

How Recursion Works

Each recursive call breaks the problem down into smaller parts and solves those parts until the base case is reached, preventing infinite recursion.

Example: Fibonacci Sequence

function fib(n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}

console.log(fib(6)); // 8

Recursion vs Iteration

  • Recursion: Elegant and simple for problems naturally defined recursively.
  • Iteration: Sometimes more efficient and avoids call stack overhead.

Common Uses of Recursion

  • Tree and graph traversals (DFS)
  • Divide and conquer algorithms (Merge Sort, Quick Sort)
  • Backtracking (e.g., puzzles, permutations)
  • Mathematical computations (factorials, Fibonacci, power functions)

Example: Sum of Array Elements

function sumArray(arr, n) {
  if (n <= 0) return 0;
  return sumArray(arr, n - 1) + arr[n - 1];
}

console.log(sumArray([1, 2, 3, 4, 5], 5)); // 15

Tips for Writing Recursive Functions

  • Define a clear base case to stop recursion.
  • Make sure each recursive call progresses toward the base case.
  • Be mindful of stack overflow for deep recursion; consider iterative alternatives if needed.
