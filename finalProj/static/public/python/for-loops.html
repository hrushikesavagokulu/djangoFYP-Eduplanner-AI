Python for Loop

Welcome to devHive! In this tutorial, you’ll explore how for loops help you repeat tasks in Python efficiently. Loops are essential for automating repetitive tasks, saving time and reducing errors.

1. What is a for Loop?

A for loop allows you to iterate over sequences such as lists, tuples, strings, or ranges. This means you can execute a block of code multiple times, once for each item in the sequence.

For example, you can loop over each element in a list, or count through a range of numbers.

2. Basic Syntax

for variable in sequence:
    # code to repeat

Here, variable takes the value of each item in the sequence, one by one, and runs the indented code block for each.


  



  



  
3. Looping Through a List

  
Lists are collections of items. You can use a for loop to access each item in the list one at a time.

  
names = ["Alice", "Bob", "Charlie"]
for name in names:
    print(name)


  
In this example, the loop prints every name stored in the names list.


  

    
    
    

  


  
4. Using the range() Function

  
The range() function generates a sequence of numbers, which is useful when you want to repeat something a specific number of times.

  
for i in range(5):
    print(i)


  
This loop prints numbers from 0 to 4. Notice that range(5) generates numbers starting at 0 up to, but not including, 5.


  
5. Looping Through Strings

  
You can loop over every character in a string.

  
for letter in "Python":
    print(letter)


  
This prints each letter of the word Python on a new line.


  
6. Nested Loops

  
Sometimes, you need loops inside loops. These are called nested loops. They are useful for working with grids, tables, or more complex data structures.

  
for i in range(1, 4):
    for j in range(1, 4):
        print(i, "*", j, "=", i * j)


  
This code prints a small multiplication table from 1 to 3.


  
7. Using break and continue

  
You can control the flow of a loop with these two statements:

  
    
    
  • break immediately stops the loop.
    • 
    
  • continue skips the current iteration and moves to the next one.
    • 
  

  
for i in range(10):
    if i == 5:
        break  # stops loop when i is 5
    print(i)


  
for i in range(5):
    if i == 2:
        continue  # skip printing when i is 2
    print(i)

9. Practical Examples


  
Print Even Numbers from 1 to 10

  
This example uses the modulo operator % to check if a number is even.

  
for i in range(1, 11):
    if i % 2 == 0:
        print(i)



  
Loop Over a Dictionary

  
Dictionaries store key-value pairs. Looping over a dictionary lets you access keys and their corresponding values.

  
info = {"name": "Alice", "age": 25}
for key in info:
    print(key, "=>", info[key])



  
Reverse a String

  
This example shows how to build a reversed version of a string by prepending characters inside a loop.

  
text = "hello"
reversed_text = ""
for char in text:
    reversed_text = char + reversed_text
print(reversed_text)
