Strings in Python - DevHive

Strings are sequences of characters enclosed in quotes. In Python, you can use single quotes ' ', double quotes " ", or triple quotes ''' ''' / """ """ for multi-line strings.

Example: Creating and printing strings

message = "Hello, DevHive!"
print(message)

multi_line = '''This is
a multi-line
string.'''
print(multi_line)

Common String Operations

Some useful string operations:

  • len(s) - Get length of string s
  • s.lower() - Convert string to lowercase
  • s.upper() - Convert string to uppercase
  • s.strip() - Remove whitespace from ends
  • s.replace(old, new) - Replace substring
  • s.split(separator) - Split string into list
  • substring in s - Check substring presence

String Formatting

Python offers several ways to format strings:

  • Using the % operator (old style)
  • Using .format() method
  • Using f-strings (Python 3.6+)
# Old style
name = "Alice"
age = 30
print("Hello, %s. You are %d years old." % (name, age))

# Using format()
print("Hello, {}. You are {} years old.".format(name, age))

# Using f-strings
print(f"Hello, {name}. You are {age} years old.")

Escape Characters

Use escape characters to include special characters in strings:

  • \\n - Newline
  • \\t - Tab
  • \\\\ - Backslash
  • \\' - Single quote
  • \\" - Double quote
print("Hello\nWorld!")
print("Column1\tColumn2")
print("This is a backslash: \\")

Useful String Methods

More handy string methods you should know:

  • s.startswith(sub) - Check if string starts with sub
  • s.endswith(sub) - Check if string ends with sub
  • s.find(sub) - Find first index of substring (returns -1 if not found)
  • s.count(sub) - Count occurrences of substring
  • s.isalpha() - Returns True if all characters are letters
  • s.isdigit() - Returns True if all characters are digits
