While Loop - DevHive (Python)

The while loop is a fundamental control structure in Python. It runs a block of code repeatedly as long as the given condition is True. It's useful when you don't know in advance how many times the loop should run.

Think of it as: “Keep executing this block while the condition holds true.”

Syntax

while condition:
    # block of code

Explanation:

  • condition is evaluated before each loop iteration.
  • If it's True, the indented block runs.
  • If it's False, the loop exits.

Visual Flow

1. Check condition → 2. If true, run code → 3. Repeat → 4. Exit when false.

Example 1: Print numbers from 1 to 5

i = 1
while i <= 5:
    print(i)
    i += 1

Try it Yourself

Example 2: Countdown from 10 to 1

num = 10
while num > 0:
    print(num)
    num -= 1

Common Mistake: Infinite Loop

If the condition never turns False, the loop will run forever.

while True:
    print("This will never stop!")
Always make sure your loop has a clear exit condition.
