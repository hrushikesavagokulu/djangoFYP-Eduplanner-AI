More on Object-Oriented Programming in Python

Classes and Objects

A class is a blueprint to create objects. An object is an instance of a class with its own attributes and methods.

Encapsulation

Encapsulation means restricting direct access to some of an object's components, which can be done using private attributes by prefixing them with __ (double underscore).

class MyClass:
    def __init__(self):
        self.__private_var = 42  # Private attribute

Inheritance

Inheritance allows a new class to inherit attributes and methods from an existing class:

class Parent:
    def greet(self):
        print("Hello from Parent")

class Child(Parent):
    pass  # Child inherits greet() from Parent

Polymorphism

Polymorphism lets methods behave differently based on the object that calls them, often through method overriding:

class Animal:
    def speak(self):
        print("Animal speaks")

class Cat(Animal):
    def speak(self):
        print("Cat meows")

Special Methods

Python classes can have special methods (also called “magic methods”) that start and end with double underscores, like __init__ for initialization or __str__ for string representation.

Example of a Complete Class

class Car:
    def __init__(self, make, model):
        self.make = make
        self.model = model

    def description(self):
        return f"{self.make} {self.model}"

car = Car("Toyota", "Corolla")
print(car.description())
