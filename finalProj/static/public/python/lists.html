Lists (Arrays) - DevHive

In JavaScript, arrays (also called lists in other languages) are used to store multiple values in a single variable. Arrays maintain the order of their elements and allow you to access each item by its index.

Array Declaration

Arrays are created by placing elements inside square brackets [], separated by commas.

const fruits = ["Apple", "Banana", "Cherry"];

Here, fruits is an array that contains three strings. Each element can be accessed using an index starting at 0: 

console.log(fruits[0]); // Outputs: Apple
console.log(fruits[2]); // Outputs: Cherry

Access and Modify Elements

You can access elements by their index and assign new values to update them: 

console.log(fruits[1]); // Banana
fruits[2] = "Orange";     // Replace "Cherry" with "Orange"
console.log(fruits);      // ["Apple", "Banana", "Orange"]

Note: Trying to access an index that doesn’t exist will return undefined.

Common Array Methods

Arrays have many built-in methods to manipulate their elements easily:

  • push(item): Adds an item to the end of the array.
  • pop(): Removes the last item and returns it.
  • shift(): Removes the first item and returns it.
  • unshift(item): Adds an item to the start of the array.
  • length: Property that returns the number of items in the array.
fruits.push("Grapes");  // Add "Grapes" at end
console.log(fruits);       // ["Apple", "Banana", "Orange", "Grapes"]

const lastFruit = fruits.pop(); // Removes "Grapes"
console.log(lastFruit);          // Outputs: Grapes
console.log(fruits.length);     // Outputs: 3

Arrays Can Store Any Data Type

Arrays can hold any combination of data types, including numbers, strings, objects, or even other arrays: 

const mixed = [42, "hello", true, { name: "Alice" }, [1, 2, 3]];
console.log(mixed[3].name); // Outputs: Alice
console.log(mixed[4][1]);   // Outputs: 2
