While Loop - DevHive (Java)

The while loop is a control structure in Java that repeatedly executes a block of code as long as the specified condition is true. It's useful when the number of iterations is not known beforehand.

Think of the while loop as: "Keep doing this, while this condition holds true."

Syntax

while (condition) {
    // code block to be executed
}

Explanation:

  • The condition is evaluated before each iteration.
  • If it’s true, the loop body executes.
  • If it’s false, the loop stops.

Visual Flow

1. Check condition → 2. If true, run code → 3. Repeat → 4. Stop when condition is false.

Example 1: Print numbers from 1 to 5

int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}

Example 2: Countdown from 10 to 1

int num = 10;
while (num > 0) {
    System.out.println(num);
    num--;
}

Common Mistake: Infinite Loop

If the condition never becomes false, the loop will continue forever, causing an infinite loop.

while (true) {
    System.out.println("This will never stop!");
}
Always ensure the loop condition changes inside the loop to avoid infinite repetition.
