Java - For Loops

A for loop in Java is a control flow statement that allows code to be executed repeatedly based on a given boolean condition. It is typically used when the number of iterations is known in advance.

Syntax

for (initialization; condition; update) {
  // code to be executed
}

- Initialization: Executes once at the beginning. Typically used to declare and initialize a counter variable.
- Condition: Evaluated before every loop iteration. If true, the loop continues; if false, the loop stops.
- Update: Executed after each iteration. Usually updates the loop control variable.

Example 1: Print numbers 1 to 5

for (int i = 1; i <= 5; i++) {
  System.out.println(i);
}
Output:
1
2
3
4
5

Example 2: Print even numbers from 2 to 10

for (int i = 2; i <= 10; i += 2) {
  System.out.println(i);
}
Output:
2
4
6
8
10

Decrementing Loop

You can also use a for loop to count backwards.

for (int i = 5; i >= 1; i--) {
  System.out.println(i);
}
Output:
5
4
3
2
1

Nested for Loops

A for loop inside another for loop is called a nested loop. Useful for working with 2D arrays or printing patterns.

for (int i = 1; i <= 3; i++) {
  for (int j = 1; j <= 2; j++) {
    System.out.println("i = " + i + ", j = " + j);
  }
}

Enhanced for Loop (For-each)

Used to iterate over arrays or collections without needing an index.

int[] numbers = {10, 20, 30};
for (int num : numbers) {
  System.out.println(num);
}
Output:
10
20
30

When to Use For Loops

  • When the number of iterations is known in advance.
  • When iterating through arrays using indexes.
  • When performance and concise control is needed.

Common Mistake

// Infinite loop - update is missing
for (int i = 1; i <= 5;) {
  System.out.println(i);
}

This loop runs forever unless i is manually updated inside the loop body.

Conclusion

The for loop is one of the most efficient and compact looping mechanisms in Java. Whether you're looping through a list, counting numbers, or printing patterns, mastering the for loop structure is essential for any Java programmer.
