Java - Loop Control

In Java, loop control statements allow you to control the flow of loops (like for, while, and do-while) in more advanced ways. These control statements include:

  • break
  • continue
  • return (used inside methods, can also affect loop behavior)

1. break Statement

The break statement is used to exit a loop prematurely. When encountered, the control exits the loop immediately and continues with the code that follows the loop.

Syntax:

break;

Example:

for (int i = 1; i <= 10; i++) {
  if (i == 5) {
    break; // loop terminates when i is 5
  }
  System.out.println(i);
}
Output: 1 2 3 4

2. continue Statement

The continue statement skips the current iteration of the loop and jumps to the next iteration.

Syntax:

continue;

Example:

for (int i = 1; i <= 5; i++) {
  if (i == 3) {
    continue; // skip number 3
  }
  System.out.println(i);
}
Output: 1 2 4 5

3. return Statement

Although return is primarily used to exit from a method and optionally return a value, if used within a loop inside a method, it exits the loop and also exits the method entirely.

Example:

public static void checkLoop() {
  for (int i = 1; i <= 5; i++) {
    if (i == 4) {
      return; // exits the method entirely
    }
    System.out.println(i);
  }
}
Output: 1 2 3

4. Labeled break and continue

Java allows using labels with break and continue to break out of nested loops.

Example (Labeled break):

outer:
for (int i = 1; i <= 3; i++) {
  for (int j = 1; j <= 3; j++) {
    if (j == 2) {
      break outer; // exits both loops
    }
    System.out.println("i = " + i + ", j = " + j);
  }
}
Output: i = 1, j = 1

Example (Labeled continue):

outer:
for (int i = 1; i <= 2; i++) {
  for (int j = 1; j <= 3; j++) {
    if (j == 2) {
      continue outer; // skips to next iteration of outer loop
    }
    System.out.println("i = " + i + ", j = " + j);
  }
}
Output: i = 1, j = 1
i = 2, j = 1

When to Use

  • Use break when you want to exit a loop early based on a condition.
  • Use continue to skip specific iterations.
  • Use labeled versions for more complex nested loop control.

Summary

Loop control statements help you manage loop execution more efficiently. Knowing when and how to use them is essential for writing clear, effective Java programs.
