Java Getting Started

Install Java Development Kit (JDK)

To write and run Java programs, you need the Java Development Kit (JDK).

Check if Java is installed by opening your command line and running:

java -version

If Java is installed, you will see the version information.

If not installed, download the latest JDK for free from Oracle Java Downloads or Adoptium OpenJDK.

Writing Your First Java Program

Use any text editor to write Java code. Save your program with a .java extension.

HelloWorld.java:

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

This program prints Hello, World! to the console.

Compile and Run Your Java Program

1. Open the command line and navigate to the folder where you saved HelloWorld.java.

2. Compile your program by running:

javac HelloWorld.java

This will create a file named HelloWorld.class.

3. Run the compiled program:

java HelloWorld

You should see:

Hello, World!

Using the Command Line Java Shell (JShell)

JShell allows you to quickly test Java code snippets without writing full programs.

Start JShell by running:

jshell

Then you can type Java statements directly, for example:

jshell> System.out.println("Hello from JShell!");

JShell will immediately execute the command and print the result.

To exit JShell, type:

/exit

Java Version Check

You can also check the installed Java version in your programs by running:

java -version

Optional: Use an IDE

For a better development experience, use an IDE like Eclipse, IntelliJ IDEA, or NetBeans.

They provide useful features like syntax highlighting, debugging, and project management.
