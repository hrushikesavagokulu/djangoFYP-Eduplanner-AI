Java Methods

Methods are blocks of code designed to perform a specific task, improve code reusability, and organize programs efficiently. In Java, methods define behavior and can accept inputs, perform operations, and return results.

Method Syntax

A typical method declaration consists of:

  • Access modifier (optional) like public, private, or protected.
  • Return type - the data type the method returns, or void if it returns nothing.
  • Method name - a valid identifier.
  • Parameter list in parentheses (can be empty).
  • Method body enclosed in curly braces {}.

Basic Syntax Example

A simple method with no parameters and no return value:

public void greet() {
    System.out.println("Hello, World!");
}

Method with Parameters

Methods can accept parameters to work with dynamic data:

public void greetUser(String name) {
    System.out.println("Hello, " + name + "!");
}

Method with Return Value

Methods can return values to the caller:

public int add(int a, int b) {
    return a + b;
}

Calling Methods

Methods are called by specifying the method name followed by parentheses. If the method belongs to an object, use the object reference:

greet(); // calling method without parameters
greetUser("Alice"); // calling method with parameter
int sum = add(5, 7); // calling method with return value

Method Overloading

Java allows multiple methods with the same name but different parameter lists (type or number), known as method overloading:

public int add(int a, int b) {
    return a + b;
}

public double add(double a, double b) {
    return a + b;
}

public int add(int a, int b, int c) {
    return a + b + c;
}

Why Use Methods?

  • Code reusability: Write once, call multiple times.
  • Modularity: Break large programs into manageable parts.
  • Maintainability: Easier to update or debug isolated code blocks.
  • Readability: Cleaner and more understandable code structure.

Example: Complete Class with Methods

This class demonstrates declaring, calling, and overloading methods:

public class Calculator {

    public void greet() {
        System.out.println("Welcome to Calculator");
    }

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public static void main(String[] args) {
        Calculator calc = new Calculator();
        calc.greet();

        System.out.println(calc.add(10, 20));
        System.out.println(calc.add(10.5, 20.5));
    }
}

Summary

Methods are fundamental in Java programming for structuring logic, enabling reuse, and supporting complex operations. Understanding method syntax, parameters, return types, and overloading is crucial for effective Java development.
