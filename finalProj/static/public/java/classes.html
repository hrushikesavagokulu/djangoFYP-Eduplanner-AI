🚀 Java Classes - Deep Dive

A class in Java acts as a blueprint from which individual objects are created. Think of it like a plan or mold for an object. Java classes encapsulate data (fields) and behavior (methods).

📦 Real-Life Analogy

Imagine a class as a car design (e.g., Tesla Model S) and the objects as actual cars built from that design.

📐 Basic Syntax of a Class

public class Car {
    String brand;
    int year;

    void drive() {
        System.out.println("The car is driving.");
    }
}

🛠️ Fields and Methods in Detail

  • Fields: Store object state
  • Methods: Define object behavior

Example

public class Dog {
    String breed;
    int age;

    void bark() {
        System.out.println("Woof!");
    }
}

✨ Constructors

Constructors initialize new objects. They share the class name and have no return type. 

public class Dog {
    String breed;

    // Constructor
    public Dog(String breed) {
        this.breed = breed;
    }
}

Constructor Overloading

Multiple constructors with different parameters

public class Rectangle {
    int length, width;

    public Rectangle() {
        length = width = 0;
    }

    public Rectangle(int l, int w) {
        length = l;
        width = w;
    }
}

🔒 Access Modifiers

ModifierMeaningAccess Scope
publicVisible to allEverywhere

🔐 Encapsulation

public class BankAccount {
    private double balance;

    public void deposit(double amount) {
        if (amount > 0) balance += amount;
    }

    public double getBalance() {
        return balance;
    }
}

🧬 Inheritance

One class inherits fields and methods of another.

class Animal {
    void eat() {
        System.out.println("Eating...");
    }
}

class Bird extends Animal {
    void fly() {
        System.out.println("Flying...");
    }
}

🌀 Polymorphism

One interface, many implementations.

class Animal {
    void sound() {
        System.out.println("Animal makes sound");
    }
}

class Cat extends Animal {
    void sound() {
        System.out.println("Meow");
    }
}

🧼 Abstraction

Hiding internal details and showing only functionality.

Using Abstract Class

abstract class Shape {
    abstract void draw();
}

class Circle extends Shape {
    void draw() {
        System.out.println("Drawing circle");
    }
}

Using Interface

interface Flyable {
    void fly();
}

class Drone implements Flyable {
    public void fly() {
        System.out.println("Drone flying...");
    }
}

🧩 Composition (HAS-A relationship)

A class can contain another class object as its field.

class Engine {
    void start() {
        System.out.println("Engine starts...");
    }
}

class Car {
    Engine engine = new Engine();

    void drive() {
        engine.start();
        System.out.println("Car moves...");
    }
}

📌 Static vs Instance

  • Static: Belongs to class, shared by all objects
  • Instance: Unique per object
class Student {
    static String college = "ABC";
    String name;
}

🏗️ Nested Classes

Java allows defining a class inside another class

class Outer {
    int x = 10;

    class Inner {
        void display() {
            System.out.println("Value: " + x);
        }
    }
}

🧠 Interview Tip

Always prepare how to explain real-world analogies like: "Class is the blueprint, object is the house built from it". Mention concepts like cohesion, modularity, SRP (Single Responsibility Principle).

✅ Summary

  • Java classes are the foundation of OOP
  • They combine fields and methods into one unit
  • OOP pillars: Encapsulation, Inheritance, Polymorphism, Abstraction
  • Use constructors, access modifiers, interfaces, and static members effectively
