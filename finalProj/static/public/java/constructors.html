Java - Constructors

A constructor in Java is a special method used to initialize objects. It is called when an instance of a class is created and is responsible for setting initial values for the object’s attributes or performing setup operations.

Key Characteristics of Constructors

  • A constructor has the same name as the class.
  • Constructors do not have a return type, not even void.
  • They are automatically called when an object is instantiated using the new keyword.
  • If no constructor is explicitly defined, Java provides a default no-argument constructor.

Types of Constructors

There are mainly two types of constructors:

  1. Default Constructor (No-Arg Constructor) — A constructor with no parameters, provided by Java if you don't write any constructors.
  2. Parameterized Constructor — A constructor with parameters to initialize an object with specific values.

Default Constructor Example

If you define no constructors in a class, the Java compiler automatically provides a default constructor that does nothing but allows the object to be created.

Parameterized Constructor Example

You can define constructors that accept arguments to initialize fields at the time of object creation.

Using this Keyword in Constructors

this refers to the current object and is used to distinguish between class attributes and parameters with the same name.

Constructor Overloading

Java supports constructor overloading, which means you can have multiple constructors in the same class with different parameter lists. The correct constructor is chosen based on the arguments passed during object creation.


public class Box {
    double width, height, depth;

    // Constructor with no parameters
    public Box() {
        width = height = depth = 0;
    }

    // Constructor with parameters
    public Box(double w, double h, double d) {
        width = w;
        height = h;
        depth = d;
    }

    // Constructor with one parameter (cube)
    public Box(double len) {
        width = height = depth = len;
    }
}

Chaining Constructors with this()

You can call one constructor from another within the same class using this(). This is called constructor chaining and helps to avoid code duplication.


public class Box {
    double width, height, depth;

    public Box() {
        this(0, 0, 0);  // Calls the parameterized constructor
    }

    public Box(double w, double h, double d) {
        width = w;
        height = h;
        depth = d;
    }
}

Important Points About Constructors

  • Constructors cannot be abstract, static, final, or synchronized.
  • If a class has at least one constructor, the default constructor is not automatically provided.
  • Constructors can be declared private to restrict object creation (e.g., singleton patterns).
  • Constructors help enforce immutability by setting final fields at object creation time.

Constructor vs Method

Feature Constructor Method
Name Must be same as class name Can have any valid identifier
Return Type No return type, not even void Has a return type or void
Purpose To initialize new objects To perform specific tasks
Invocation Automatically called when object is created Called explicitly on objects or classes
Inheritance Constructors are not inherited Methods can be inherited and overridden

Common Uses of Constructors

  • Initialize object attributes with default or user-supplied values.
  • Perform validation or setup logic during object creation.
  • Overload constructors to provide multiple ways to instantiate objects.
  • Enforce constraints and immutability on class data.

Constructor in Inheritance

When dealing with inheritance, subclass constructors implicitly call the superclass’s no-argument constructor unless super() is explicitly called with parameters.


class Animal {
    Animal() {
        System.out.println("Animal created");
    }
}

class Dog extends Animal {
    Dog() {
        super();  // Calls Animal() constructor explicitly (optional if no args)
        System.out.println("Dog created");
    }
}

Summary

Constructors are essential in Java for creating and initializing objects. They provide control over how objects start their life cycle, allowing the programmer to set initial values, enforce rules, and offer flexible ways to create objects using overloading and chaining. Understanding constructors is fundamental to mastering Java’s object-oriented programming paradigm.
