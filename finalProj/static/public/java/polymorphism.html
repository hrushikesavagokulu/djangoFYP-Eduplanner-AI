Java Polymorphism

Polymorphism is one of the core concepts of object-oriented programming (OOP) in Java. It allows objects to be treated as instances of their parent class rather than their actual class. The word "polymorphism" means "many forms," and in Java, it means that a single interface can represent different underlying forms (data types).

Types of Polymorphism

  • Compile-time Polymorphism (Method Overloading): Multiple methods in the same class have the same name but different parameters.
  • Runtime Polymorphism (Method Overriding): A subclass provides a specific implementation of a method that is already defined in its superclass.

Why Use Polymorphism?

  • It improves code flexibility and reusability by allowing one interface to be used for a general class of actions.
  • Makes the code easier to extend and maintain.
  • Supports the design principle "Program to an interface, not an implementation."

Compile-time Polymorphism (Method Overloading)

Method overloading occurs when multiple methods share the same name but have different parameters (number, type, or order). The compiler decides which method to invoke based on the method signature.

Syntax

class Example {
    void display(int a) {
        System.out.println("Argument: " + a);
    }
    void display(int a, int b) {
        System.out.println("Arguments: " + a + " and " + b);
    }
}

Runtime Polymorphism (Method Overriding)

Method overriding happens when a subclass provides a specific implementation for a method already defined in its superclass. The method to be executed is determined at runtime based on the object's actual class, not the reference type.

Syntax

class Animal {
    void sound() {
        System.out.println("Animal makes a sound");
    }
}
class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

Example

You can create an object of subclass Dog but refer to it by superclass Animal type:

Animal myDog = new Dog();
myDog.sound();  // Output: Dog barks

Key Points

  • Method overriding requires the same method signature.
  • Overridden methods must have the same return type (or a subtype) and access level.
  • Use @Override annotation to indicate overriding explicitly.
  • Polymorphism enables dynamic method dispatch, where the call to an overridden method is resolved at runtime.

Benefits of Polymorphism

  • Allows for flexible and easily maintainable code.
  • Supports loose coupling between classes.
  • Makes it easier to add new functionality without modifying existing code.

Summary

Polymorphism enables one interface to be used for a general class of actions, while the specific action is determined by the exact nature of the situation. It is a powerful feature in Java that promotes code reuse, flexibility, and scalability.
