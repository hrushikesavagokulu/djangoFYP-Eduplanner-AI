Java - Method Overloading

Method Overloading is a feature in Java that allows a class to have more than one method with the same name, as long as their parameter lists are different. It enhances readability and enables you to define multiple behaviors with the same method name depending on the input.

Why Use Method Overloading?

  • To perform similar operations with different types or numbers of inputs.
  • To increase code reusability and readability.
  • To provide flexibility to the developer and simplify API design.

Rules for Method Overloading

  • Methods must have the same name.
  • The number of parameters must be different, or
  • The type of parameters must be different, or
  • The order of parameters must be different (if types differ).
  • Return type alone is not sufficient to distinguish overloaded methods.

Basic Syntax

class MyClass {
  void display(int a) { ... }
  void display(double a) { ... }
  void display(int a, int b) { ... }
}

Examples of Method Overloading

Example 1: Overloading by Number of Parameters

public class Calculator {
  void add(int a, int b) {
    System.out.println("Sum of 2 numbers: " + (a + b));
  }

  void add(int a, int b, int c) {
    System.out.println("Sum of 3 numbers: " + (a + b + c));
  }

  public static void main(String[] args) {
    Calculator c = new Calculator();
    c.add(10, 20);
    c.add(10, 20, 30);
  }
}

Example 2: Overloading by Type of Parameters

public class Display {
  void show(String name) {
    System.out.println("Name: " + name);
  }

  void show(int age) {
    System.out.println("Age: " + age);
  }

  public static void main(String[] args) {
    Display d = new Display();
    d.show("Alice");
    d.show(25);
  }
}

Example 3: Overloading by Order of Parameters

public class PrintData {
  void print(String name, int id) {
    System.out.println("Name: " + name + ", ID: " + id);
  }

  void print(int id, String name) {
    System.out.println("ID: " + id + ", Name: " + name);
  }

  public static void main(String[] args) {
    PrintData p = new PrintData();
    p.print("Bob", 100);
    p.print(101, "Alice");
  }
}

Invalid Overloading

You cannot overload methods based on return type alone:

int add(int a, int b) { return a + b; }
double add(int a, int b) { return a + b; } // Error! Same signature, different return type.

Overloading and Type Promotion

If a matching method is not found, Java automatically promotes smaller data types:

void show(int a) { ... }

show('A');  // char gets promoted to int

Overloading main() Method

You can overload the main() method as well, although only the standard main(String[] args) is invoked by the JVM:

public class MainTest {
  public static void main(String[] args) {
    System.out.println("Main with String[] args");
    main(10);
  }

  public static void main(int a) {
    System.out.println("Main with int: " + a);
  }
}

Advantages of Method Overloading

  • Makes code cleaner and easier to read.
  • Reduces duplication of logic.
  • Allows methods to handle different types of data flexibly.

Conclusion

Method overloading is a fundamental OOP feature in Java that enhances the power and flexibility of your code. By providing multiple definitions for the same method name, you can simplify your logic while improving readability and maintainability.
