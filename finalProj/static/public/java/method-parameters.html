Method Parameters

Method parameters allow you to pass information or values into methods so that they can perform tasks using dynamic inputs. They act as variables declared within the parentheses of a method definition.

Why Use Parameters?

  • Make methods more flexible and reusable.
  • Allow methods to operate on different data without rewriting code.
  • Help pass multiple values to methods.

Syntax of Method Parameters

Parameters are defined inside the parentheses of a method header. You can define zero or more parameters, separated by commas. Each parameter has a type and a name:

accessModifier returnType methodName(type1 param1, type2 param2, ...) {
    // method body
}

Example: Method with Parameters

This method takes two integers as parameters and prints their sum:

public void printSum(int a, int b) {
  int sum = a + b;
  System.out.println("Sum is: " + sum);
}

Calling a Method with Parameters

You provide arguments (values) when calling the method, matching the parameter list in order and type:

printSum(5, 10);  // Output: Sum is: 15

Parameter Types

  • Primitive types: int, double, boolean, char, etc.
  • Reference types: objects like String, arrays, custom classes.

Example with Different Parameter Types

public void greetUser(String name, int age) {
  System.out.println("Hello " + name + ", you are " + age + " years old.");
}

Passing Parameters by Value

In Java, method parameters are passed by value. This means:

  • For primitive types, a copy of the value is passed.
  • For objects, a copy of the reference is passed (not the object itself).

Thus, changes to parameters inside the method do not affect the original variables (except when modifying the object's internal state).

Variable Number of Parameters (Varargs)

Java supports variable-length argument lists using the ... syntax, allowing methods to accept zero or more arguments of a specified type:

public void printNumbers(int... numbers) {
  for (int num : numbers) {
    System.out.println(num);
  }
}

Example Usage of Varargs

printNumbers(1, 2, 3, 4);

Summary

Method parameters are essential to write flexible and reusable methods. They allow passing information into methods to operate on different inputs, supporting varied program behavior.
