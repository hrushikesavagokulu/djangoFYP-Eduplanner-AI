Java Method Overriding

Method Overriding is a feature in Java where a subclass provides a specific implementation of a method that is already defined in its superclass. It allows a subclass to modify or extend the behavior of the inherited method.

Why Use Overriding?

  • To provide a specific implementation of a method that is more appropriate for the subclass.
  • To achieve runtime polymorphism, enabling dynamic method dispatch.
  • To change or extend the behavior of the parent class method without modifying the parent class.

Rules for Overriding

  • The method must have the same name, return type, and parameter list as the method in the superclass.
  • The overriding method cannot have more restrictive access than the overridden method.
  • Only inherited methods can be overridden; static methods cannot be overridden but can be hidden.
  • The method cannot be overridden if it is marked final or private.

Syntax

class Parent {
    void display() {
        System.out.println("Parent display");
    }
}

class Child extends Parent {
@Override
void display() {
System.out.println("Child display");
}
}

Key Points

  • The @Override annotation is optional but helps catch errors at compile time.
  • Overriding allows Java to decide at runtime which method to execute based on the object's actual type.
  • Overriding supports the principle of “programming to an interface, not implementation”.

Example

When a method is overridden, the subclass method is called even if the object is referred to by a superclass reference:

Parent obj = new Child();
obj.display(); // Output: Child display

Summary

Method overriding is a fundamental mechanism in Java's polymorphism that allows a subclass to provide a customized behavior of an inherited method. It promotes flexibility and extensibility in object-oriented design.
