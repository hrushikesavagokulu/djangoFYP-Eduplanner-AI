Java Syntax — Hands-On Tutorial

Running Java Code

Java programs are saved with the .java extension and run via the Java Virtual Machine (JVM).

Example command line:

javac HelloWorld.java
java HelloWorld

Basic Java Program

This is the simplest Java program:

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Comments

Java supports:

  • Single-line comments with //
  • Multi-line comments with /* ... */
// This is a single-line comment
/* This is
   a multi-line comment */

Java Keywords

Reserved words include:

class, public, static, void, int, double, if, else, while, for, return, new, try, catch, finally, this, super, extends, implements

Data Types

Some common data types:

int number = 10;
double price = 5.99;
char letter = 'A';
boolean isActive = true;
String text = "Hello";

Control Structures

Example of an if statement:

if (number > 5) {
    System.out.println("Number is greater than 5");
} else {
    System.out.println("Number is 5 or less");
}
