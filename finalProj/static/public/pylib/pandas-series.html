Working with Series and DataFrames

Pandas is a powerful Python library used for data manipulation and analysis. Its two primary data structures are Series and DataFrame. Understanding these is essential for effective data analysis.

1. Pandas Series

A Series is a one-dimensional labeled array capable of holding any data type.

Creating a Series

import pandas as pd

# Create a Series from a list
data = [10, 20, 30, 40]
s = pd.Series(data)
print(s)

Output:

0    10
1    20
2    30
3    40
dtype: int64

Custom Index

s = pd.Series(data, index=['a', 'b', 'c', 'd'])
print(s)

Output:

a    10
b    20
c    30
d    40
dtype: int64

Accessing Series Elements

You can access elements by position or index label:

print(s[0])   # Access by position
print(s['a']) # Access by label

2. Pandas DataFrame

A DataFrame is a two-dimensional labeled data structure with columns of potentially different types.

Creating a DataFrame

import pandas as pd

# Create a DataFrame from a dictionary
data = {
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'City': ['New York', 'Los Angeles', 'Chicago']
}

df = pd.DataFrame(data)
print(df)

Output:

      Name  Age         City
0    Alice   25     New York
1      Bob   30  Los Angeles
2  Charlie   35      Chicago

Accessing Columns

Access a column as a Series:

print(df['Name'])

Accessing Rows

Use loc and iloc for label-based and position-based indexing:

print(df.loc[0])  # Row by label
print(df.iloc[1]) # Row by position

Adding a New Column

df['Salary'] = [50000, 60000, 70000]
print(df)

Basic DataFrame Operations

  • df.head() — View the first few rows
  • df.describe() — Get summary statistics
  • df.info() — Get DataFrame info including data types
  • df.shape — Get dimensions (rows, columns)

3. Summary

  • Series is a one-dimensional labeled array.
  • DataFrame is a two-dimensional table with labeled rows and columns.
  • Pandas provides flexible and powerful data manipulation capabilities.
Note: Pandas integrates well with other Python libraries such as NumPy and Matplotlib for advanced data analysis and visualization.
