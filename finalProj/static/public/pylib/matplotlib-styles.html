Customizing Plots in Matplotlib

Matplotlib is a powerful Python library for creating static, animated, and interactive visualizations. One of its strengths is the ability to customize every aspect of a plot — from colors and line styles to fonts and layouts — to make your data more insightful and visually appealing.

1. Basic Plot Customization

You can customize simple plot elements like color, line style, marker style, and labels using parameters in plotting functions.

import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 10, 100)
y = np.sin(x)

plt.plot(x, y, color='red', linestyle='--', marker='o', label='sin(x)')
plt.title('Sine Wave')
plt.xlabel('X-axis')
plt.ylabel('Y-axis')
plt.legend()
plt.show()
  • color: Defines the color of the line or markers (e.g., 'red', '#00FF00', 'r').
  • linestyle: Can be solid ('-'), dashed ('--'), dash-dot ('-.'), or dotted (':').
  • marker: Marks data points with symbols like 'o' (circle), 's' (square), '^' (triangle), etc.
  • label: Adds a label for the legend.

2. Changing Plot Size and Resolution

You can control the figure size and DPI (dots per inch) which impacts the resolution.

plt.figure(figsize=(8, 4), dpi=100)
plt.plot(x, y)
plt.title('Figure size 8x4 inches')
plt.show()
  • figsize=(width, height): Size in inches.
  • dpi: Controls resolution, higher means sharper images.

3. Using Stylesheets

Matplotlib supports predefined style sheets that change the look and feel of plots globally.

plt.style.use('ggplot')  # Other examples: 'seaborn', 'bmh', 'dark_background'

plt.plot(x, y)
plt.title('Using ggplot style')
plt.show()

You can list all available styles using:

print(plt.style.available)

4. Customizing Fonts and Text

Matplotlib allows detailed control over fonts for titles, labels, legends, and annotations.

plt.plot(x, y)
plt.title('Custom Font Title', fontsize=16, fontweight='bold', color='purple', family='serif')
plt.xlabel('X-axis Label', fontsize=12)
plt.ylabel('Y-axis Label', fontsize=12)
plt.show()
  • fontsize: Size of the font.
  • fontweight: Thickness like 'normal', 'bold'.
  • family: Font family such as 'serif', 'sans-serif', 'monospace'.

5. Adding Grid, Legends, and Annotations

Grids help in reading values, legends explain plot lines, and annotations add notes at specific points.

plt.plot(x, y, label='sin(x)')
plt.grid(True, linestyle='--', color='gray', alpha=0.7)
plt.legend(loc='upper right')
plt.annotate('Peak', xy=(np.pi/2, 1), xytext=(np.pi/2+1, 0.8),
             arrowprops=dict(facecolor='black', shrink=0.05))
plt.show()
  • plt.grid() parameters: linestyle, color, alpha (transparency).
  • plt.legend(): Position can be controlled with loc (e.g., 'upper right').
  • plt.annotate(): Used to add annotations with arrows or text.

6. Multiple Subplots and Layouts

You can create multiple plots in a grid layout within one figure and customize each subplot.

fig, axs = plt.subplots(2, 2, figsize=(10, 8))

axs[0, 0].plot(x, np.sin(x))
axs[0, 0].set_title('Sine')

axs[0, 1].plot(x, np.cos(x), 'r--')
axs[0, 1].set_title('Cosine')

axs[1, 0].plot(x, np.tan(x), 'g-.')
axs[1, 0].set_ylim(-10, 10)  # Limit y-axis to avoid extreme values
axs[1, 0].set_title('Tangent')

axs[1, 1].plot(x, np.log1p(x), 'm:')
axs[1, 1].set_title('Logarithm')

plt.tight_layout()
plt.show()

7. Saving Figures

Save your plots in various formats like PNG, PDF, SVG, etc.

plt.plot(x, y)
plt.title('Save plot example')
plt.savefig('plot.png', dpi=300, bbox_inches='tight')  # Saves high-res image
plt.close()

Summary

  • Use parameters like color, linestyle, and marker to customize plot appearance.
  • Change figure size with figsize and resolution with dpi.
  • Apply predefined stylesheets to quickly change overall aesthetics.
  • Customize fonts and add grids, legends, and annotations for clarity.
  • Create multiple subplots for complex visualizations.
  • Save figures with control over format and quality.
