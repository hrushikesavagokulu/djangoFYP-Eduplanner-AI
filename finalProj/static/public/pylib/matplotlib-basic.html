Advanced Plotting with Matplotlib

Once you are comfortable with basic plotting, Matplotlib offers a wide range of advanced features for creating professional and complex visualizations.

Plotting with Subplots

Organize multiple plots in one figure using subplots:

import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)

fig, axs = plt.subplots(2, 1, figsize=(8, 6))

axs[0].plot(x, y1, color='blue')
axs[0].set_title('Sine Wave')

axs[1].plot(x, y2, color='green')
axs[1].set_title('Cosine Wave')

plt.tight_layout()
plt.show()

Using Different Plot Types Together

Combine multiple plot types in one figure to enrich the visualization:

plt.plot(x, y1, label='Sine', color='blue')
plt.scatter(x, y2, label='Cosine points', color='red')
plt.title('Line and Scatter Plot Combined')
plt.xlabel('X-axis')
plt.ylabel('Y-axis')
plt.legend()
plt.show()

Customizing Axes

Control ticks, limits, and scales for better focus and clarity:

plt.plot(x, y1)
plt.xlim(0, 8)
plt.ylim(-1, 1)
plt.xticks([0, 2, 4, 6, 8])
plt.yscale('linear')  # other options: 'log', 'symlog', 'logit'
plt.title('Custom Axes Limits and Scale')
plt.show()

Annotations and Text

Add descriptive text and annotations to highlight key data points:

plt.plot(x, y1)
plt.annotate('Max', xy=(np.pi/2, 1), xytext=(2, 1.2),
             arrowprops=dict(facecolor='black', shrink=0.05))
plt.text(7, -0.5, 'Sine curve example', fontsize=12, color='purple')
plt.title('Annotations and Text')
plt.show()

Custom Legends and Colors

Adjust legend placement and use custom colors:

plt.plot(x, y1, label='Sine', color='#1f77b4')
plt.plot(x, y2, label='Cosine', color='#ff7f0e')
plt.legend(loc='upper right', fontsize='small', shadow=True)
plt.title('Custom Legend and Colors')
plt.show()

Saving Figures with Transparency

Save plots with transparent backgrounds and different formats:

plt.plot(x, y1)
plt.title('Save with Transparency')
plt.savefig('transparent_plot.png', dpi=300, transparent=True)
plt.close()

Summary

  • Create multiple plots with subplots() for better layout control.
  • Mix plot types like lines and scatter to enrich visual storytelling.
  • Customize axes limits, ticks, and scales for precise control.
  • Add annotations and text for clarity and emphasis.
  • Use custom colors and position legends thoughtfully.
  • Save plots with options like transparency for professional presentation.
