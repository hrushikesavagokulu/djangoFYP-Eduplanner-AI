Introduction to Pandas for Data Manipulation

Pandas is a popular Python library designed for efficient data manipulation and analysis. It provides powerful data structures like Series and DataFrame to work with labeled and relational data in a flexible way.

Why Use Pandas?

  • Handle missing data gracefully.
  • Powerful, easy-to-use data structures.
  • Efficient slicing, indexing, and subsetting of data.
  • Data alignment and integrated handling of time series data.
  • Read/write support for a wide variety of file formats like CSV, Excel, JSON, SQL, and more.

Key Data Structures

1. Series

A one-dimensional labeled array capable of holding any data type.

import pandas as pd

# Create a Series from a list
s = pd.Series([10, 20, 30, 40])
print(s)

Output:

0    10
1    20
2    30
3    40
dtype: int64

2. DataFrame

A two-dimensional labeled data structure with columns of potentially different types.

import pandas as pd

# Create a DataFrame from a dictionary
data = {
  'Name': ['Alice', 'Bob', 'Charlie'],
  'Age': [25, 30, 35],
  'City': ['New York', 'Los Angeles', 'Chicago']
}

df = pd.DataFrame(data)
print(df)

Output:

      Name  Age         City
0    Alice   25     New York
1      Bob   30  Los Angeles
2  Charlie   35      Chicago

Basic Operations

  • df.head() - Displays the first 5 rows.
  • df.info() - Shows summary info about the DataFrame.
  • df.describe() - Generates descriptive statistics.
  • df['column_name'] - Access a single column as a Series.
  • df[['col1', 'col2']] - Access multiple columns as a DataFrame.

Reading and Writing Data

Pandas supports loading data from and saving data to many file formats:

# Read data from CSV
df = pd.read_csv('data.csv')

# Write data to Excel
df.to_excel('output.xlsx', index=False)

Summary

Pandas simplifies data manipulation tasks and is widely used in data analysis, data science, and machine learning workflows. Understanding the basics of Pandas is essential for effective data handling in Python.
