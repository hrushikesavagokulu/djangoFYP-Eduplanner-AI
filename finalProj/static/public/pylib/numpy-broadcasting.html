Broadcasting and Vectorization in NumPy

Broadcasting is a powerful mechanism that allows NumPy to work with arrays of different shapes during arithmetic operations.

What is Broadcasting?

Broadcasting automatically expands the smaller array across the larger array so they have compatible shapes for element-wise operations without copying data.

Example of broadcasting

import numpy as np

# 1D array
a = np.array([1, 2, 3])

# Scalar value (0-dimensional array)
b = 5

# Adding scalar to array broadcasts scalar across the array
print(a + b)  # Output: [6 7 8]

Rules of Broadcasting

NumPy applies these rules to determine if arrays are compatible for broadcasting:

  1. If arrays have different number of dimensions, prepend 1s to the shape of the smaller array.
  2. Arrays are compatible in a dimension if they are equal or one of them is 1.
  3. If all dimensions are compatible, broadcasting occurs.

Example: Different shaped arrays

# a shape: (3, 1)
a = np.array([[1], [2], [3]])

# b shape: (1, 4)
b = np.array([10, 20, 30, 40])

# Result shape: (3, 4) - broadcasted
print(a + b)
# Output:
# [[11 21 31 41]
#  [12 22 32 42]
#  [13 23 33 43]]

Why Broadcasting is Useful

  • Avoids explicit loops in Python, leading to faster, more readable code.
  • Efficient memory use since data isn’t duplicated.
  • Enables vectorized operations, which leverage optimized C routines under the hood.

Vectorization

Vectorization means replacing explicit loops with array operations that apply to entire arrays at once. This improves performance and makes code concise.

Example: Vectorized operations

# Without vectorization (using loop)
result = []
for x in range(1, 6):
    result.append(x * 2)
print(result)  # [2, 4, 6, 8, 10]

# With vectorization
arr = np.array([1, 2, 3, 4, 5])
print(arr * 2)  # [2 4 6 8 10]

Summary

Broadcasting and vectorization are core to NumPy’s power, enabling high-performance, concise code for numerical computations.
