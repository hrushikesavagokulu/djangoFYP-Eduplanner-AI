Using GroupBy and Aggregation in Pandas

GroupBy is a powerful feature in Pandas used to split data into groups based on some criteria, apply a function to each group independently, and then combine the results back together. This is especially useful for summarizing data and performing aggregation.

How GroupBy Works

  • Split: The data is split into groups based on some column(s).
  • Apply: A function is applied to each group independently (e.g., sum, mean, count).
  • Combine: The results are combined into a new data structure.

Basic Syntax

df.groupby('column_name').aggregation_function()

Example: Grouping and Summarizing Data

import pandas as pd

# Sample data
data = {
    'Department': ['Sales', 'Sales', 'HR', 'HR', 'IT', 'IT'],
    'Employee': ['Alice', 'Bob', 'Charlie', 'David', 'Eve', 'Frank'],
    'Salary': [70000, 72000, 50000, 52000, 60000, 61000],
    'Bonus': [5000, 4000, 3000, 3500, 4500, 4800]
}

df = pd.DataFrame(data)

# Group by Department and calculate mean salary
mean_salary = df.groupby('Department')['Salary'].mean()
print(mean_salary)

Output:


Department
HR       51000.0
IT       60500.0
Sales    71000.0
Name: Salary, dtype: float64

Common Aggregation Functions

  • sum() — Sum of values
  • mean() — Average value
  • count() — Count of non-null values
  • min() and max() — Minimum and maximum values
  • std() — Standard deviation

Using Multiple Aggregations

You can apply multiple aggregation functions at once using the agg() method.

# Multiple aggregations on Salary and Bonus
agg_data = df.groupby('Department').agg({
    'Salary': ['mean', 'max', 'min'],
    'Bonus': ['sum', 'mean']
})

print(agg_data)

Output:


           Salary             Bonus      
             mean    max    min    sum    mean
Department                                   
HR        51000.0  52000  50000   6500  3250.0
IT        60500.0  61000  60000   9300  4650.0
Sales     71000.0  72000  70000   9000  4500.0

Grouping by Multiple Columns

You can group data by multiple columns by passing a list to groupby().

# Group by Department and Employee, then sum Salary and Bonus
grouped = df.groupby(['Department', 'Employee']).sum()
print(grouped)

Output:


                       Salary  Bonus
Department Employee                  
HR         Charlie       50000   3000
           David         52000   3500
IT         Eve           60000   4500
           Frank         61000   4800
Sales      Alice         70000   5000
           Bob           72000   4000

Transformations vs Aggregations

  • Aggregation: Reduces each group to a single value per column.
  • Transformation: Returns a modified version of the original data with the same shape, often used for normalization or filling missing values within groups.
# Normalize salary within each department using transform
df['Salary_Normalized'] = df.groupby('Department')['Salary'].transform(lambda x: (x - x.mean()) / x.std())
print(df)

Output:


  Department Employee  Salary  Bonus  Salary_Normalized
0      Sales    Alice   70000   5000          -0.707107
1      Sales      Bob   72000   4000           0.707107
2         HR  Charlie   50000   3000          -0.707107
3         HR    David   52000   3500           0.707107
4         IT      Eve   60000   4500          -0.707107
5         IT    Frank   61000   4800           0.707107

Filtering Groups

You can filter groups based on a condition using the filter() method.

# Keep only departments with average salary > 60000
high_salary_departments = df.groupby('Department').filter(lambda x: x['Salary'].mean() > 60000)
print(high_salary_departments)

Output:


  Department Employee  Salary  Bonus
0      Sales    Alice   70000   5000
1      Sales      Bob   72000   4000
4         IT      Eve   60000   4500
5         IT    Frank   61000   4800

Summary

The groupby() functionality in Pandas is extremely versatile and allows you to easily summarize, transform, and filter grouped data with just a few lines of code. It’s an essential tool for data analysis and aggregation.
