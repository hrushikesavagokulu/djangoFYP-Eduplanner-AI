Statistics and Scientific Functions using SciPy

SciPy is a Python-based ecosystem of open-source software for mathematics, science, and engineering. One of its most powerful modules is scipy.stats, which provides tools for statistical computations.

1. Importing SciPy

from scipy import stats

2. Descriptive Statistics

Mean, Median, Mode, Variance, Standard Deviation:

import numpy as np
data = [4, 5, 1, 2, 7, 5, 3, 5]

print("Mean:", np.mean(data))
print("Median:", np.median(data))
print("Mode:", stats.mode(data, keepdims=True))
print("Variance:", np.var(data))
print("Standard Deviation:", np.std(data))

3. Probability Distributions

Normal Distribution

# Generate values
x = np.linspace(-3, 3, 100)
y = stats.norm.pdf(x, loc=0, scale=1)

# Random samples
samples = stats.norm.rvs(loc=0, scale=1, size=10)

Binomial Distribution

# PMF of binomial distribution
p = stats.binom.pmf(k=2, n=10, p=0.5)
print("P(X=2):", p)

4. Hypothesis Testing

t-test (Independent)

# Two sample t-test
group1 = [23, 21, 25, 30, 22]
group2 = [31, 35, 29, 32, 30]

t_stat, p_val = stats.ttest_ind(group1, group2)
print("t-statistic:", t_stat, "p-value:", p_val)

Chi-Square Test

observed = [30, 10, 20]
expected = [20, 20, 20]

chi2, p = stats.chisquare(f_obs=observed, f_exp=expected)
print("Chi-square stat:", chi2, "p-value:", p)

5. Correlation and Covariance

x = [1, 2, 3, 4, 5]
y = [5, 4, 3, 2, 1]

# Pearson correlation
r, p_val = stats.pearsonr(x, y)
print("Pearson Correlation:", r)

# Spearman correlation
rho, p_val = stats.spearmanr(x, y)
print("Spearman Correlation:", rho)

6. Confidence Intervals

mean = np.mean(data)
sem = stats.sem(data)  # standard error of mean
ci = stats.t.interval(0.95, len(data)-1, loc=mean, scale=sem)

print("95% Confidence Interval:", ci)

7. Summary

  • scipy.stats offers a broad set of statistical tools.
  • Supports both descriptive and inferential statistics.
  • Includes probability distributions, hypothesis tests, correlation, and more.
Note: Combine SciPy with NumPy and Matplotlib for full power in data science workflows.
