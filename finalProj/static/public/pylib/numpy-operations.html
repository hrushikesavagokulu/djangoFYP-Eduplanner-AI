Array Operations using NumPy

NumPy is the fundamental package for numerical computing in Python. It provides powerful tools to create and manipulate arrays efficiently.

Creating Arrays

You can create arrays from lists or tuples, or use built-in functions:

import numpy as np

# Create a 1D array from a list
arr = np.array([1, 2, 3, 4, 5])

# Create a 2D array from a list of lists
matrix = np.array([[1, 2], [3, 4]])

# Create arrays of zeros, ones, or empty
zeros = np.zeros((3, 3))
ones = np.ones((2, 4))
empty = np.empty((2, 2))  # Uninitialized values

Basic Array Operations

  • arr + 5: Adds 5 to every element.
  • arr * 2: Multiplies every element by 2.
  • arr - 1: Subtracts 1 from every element.
  • arr / 2: Divides every element by 2.
  • arr ** 2: Squares every element.
arr = np.array([1, 2, 3, 4])
print(arr + 5)  # Output: [6 7 8 9]
print(arr * 2)  # Output: [2 4 6 8]

Element-wise Mathematical Functions

NumPy provides many element-wise functions:

np.sqrt(arr)     # Square root
np.exp(arr)      # Exponential
np.log(arr)      # Natural logarithm
np.sin(arr)      # Sine
np.cos(arr)      # Cosine

Aggregation Functions

Calculate summary statistics:

np.sum(arr)        # Sum of elements
np.mean(arr)       # Mean value
np.median(arr)     # Median value
np.std(arr)        # Standard deviation
np.min(arr)        # Minimum value
np.max(arr)        # Maximum value

Array Indexing and Slicing

Access and modify parts of arrays:

arr = np.array([10, 20, 30, 40, 50])
print(arr[1])       # Output: 20
print(arr[1:4])     # Output: [20 30 40]

arr[2] = 100        # Modify element at index 2
print(arr)          # Output: [10  20 100  40  50]

Multi-dimensional Array Operations

Operations on matrices:

mat1 = np.array([[1, 2], [3, 4]])
mat2 = np.array([[5, 6], [7, 8]])

# Element-wise addition
print(mat1 + mat2)

# Matrix multiplication (dot product)
print(np.dot(mat1, mat2))

# Transpose of a matrix
print(mat1.T)

Broadcasting

NumPy supports broadcasting, allowing operations on arrays of different shapes:

arr = np.array([1, 2, 3])
mat = np.array([[1, 1, 1],
                [2, 2, 2]])

print(mat + arr)  # arr is broadcasted to match mat's shape

Reshaping Arrays

Change the shape of arrays without changing data:

arr = np.arange(12)
print(arr.reshape(3, 4))   # 3 rows, 4 columns
print(arr.reshape(-1, 6))  # Automatically calculates rows

Example: Combining Operations

import numpy as np

# Create an array of integers from 1 to 10
arr = np.arange(1, 11)

# Compute squares
squares = arr ** 2

# Compute mean of squares
mean_squares = np.mean(squares)

print("Array:", arr)
print("Squares:", squares)
print("Mean of squares:", mean_squares)
