Evaluating Machine Learning Models

Evaluating a model's performance is crucial in determining how well it generalizes to new, unseen data. Scikit-learn provides various tools and metrics for evaluating both classification and regression models.

1. Train/Test Split

The most basic evaluation technique is splitting your dataset into a training set and a testing set.

from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

2. Classification Metrics

2.1 Accuracy

Measures the ratio of correctly predicted labels over the total samples.

from sklearn.metrics import accuracy_score

accuracy = accuracy_score(y_test, y_pred)
print("Accuracy:", accuracy)

2.2 Confusion Matrix

Gives a summary of prediction results on a classification problem.

from sklearn.metrics import confusion_matrix

print(confusion_matrix(y_test, y_pred))

2.3 Precision, Recall, F1-score

from sklearn.metrics import classification_report

print(classification_report(y_test, y_pred))

3. Regression Metrics

3.1 Mean Absolute Error (MAE)

from sklearn.metrics import mean_absolute_error

mae = mean_absolute_error(y_test, y_pred)
print("MAE:", mae)

3.2 Mean Squared Error (MSE)

from sklearn.metrics import mean_squared_error

mse = mean_squared_error(y_test, y_pred)
print("MSE:", mse)

3.3 R² Score (Coefficient of Determination)

from sklearn.metrics import r2_score

r2 = r2_score(y_test, y_pred)
print("R² Score:", r2)

4. Cross-Validation

Cross-validation is a more reliable evaluation method than a single train/test split.

from sklearn.model_selection import cross_val_score

scores = cross_val_score(model, X, y, cv=5)
print("Cross-Validation Scores:", scores)
print("Average Score:", scores.mean())
Tip: Use StratifiedKFold for classification problems to preserve the distribution of target classes.

5. Visual Evaluation

You can visualize performance using ROC curves, precision-recall curves, and residual plots.

from sklearn.metrics import RocCurveDisplay

RocCurveDisplay.from_estimator(model, X_test, y_test)

6. Summary

  • Use appropriate metrics based on your problem type (classification or regression).
  • Always split your data or use cross-validation to get reliable performance metrics.
  • Scikit-learn provides many evaluation utilities built-in.
