Data Preprocessing with Scikit-learn

Scikit-learn provides robust tools to clean, transform, and prepare data for machine learning models. Proper preprocessing is critical to ensure the quality and performance of your models.

1. What is Data Preprocessing?

  • Transforming raw data into a clean dataset suitable for modeling.
  • Includes handling missing values, encoding categorical variables, scaling, normalization, and more.

2. Handling Missing Values

Using SimpleImputer


from sklearn.impute import SimpleImputer
import numpy as np

data = [[1, 2], [np.nan, 3], [7, 6]]
imputer = SimpleImputer(strategy='mean')
print(imputer.fit_transform(data))

3. Encoding Categorical Data

Label Encoding


from sklearn.preprocessing import LabelEncoder

le = LabelEncoder()
labels = ['cat', 'dog', 'dog', 'mouse']
encoded = le.fit_transform(labels)
print(encoded)

One-Hot Encoding


from sklearn.preprocessing import OneHotEncoder
import numpy as np

encoder = OneHotEncoder(sparse=False)
data = np.array([['Male'], ['Female'], ['Male']])
print(encoder.fit_transform(data))
Note: Use ColumnTransformer to apply different encoders to different columns in a pipeline.

4. Feature Scaling

Standardization (Z-score)


from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
data = [[1, 2], [3, 4], [5, 6]]
print(scaler.fit_transform(data))

Normalization (Min-Max Scaling)


from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()
print(scaler.fit_transform(data))

5. Binarization


from sklearn.preprocessing import Binarizer

binarizer = Binarizer(threshold=2.5)
data = [[1], [2], [3], [4]]
print(binarizer.fit_transform(data))

6. Polynomial Features

Useful for adding interaction terms or polynomial terms to a model.


from sklearn.preprocessing import PolynomialFeatures

poly = PolynomialFeatures(degree=2)
data = [[2, 3]]
print(poly.fit_transform(data))

7. Scaling for Sparse Data

If you're working with sparse matrices (e.g., from text data), use MaxAbsScaler.


from sklearn.preprocessing import MaxAbsScaler

scaler = MaxAbsScaler()
X = [[1, 2], [2, 0], [0, 5]]
print(scaler.fit_transform(X))

8. Using Pipelines for Efficient Preprocessing


from sklearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression

pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('clf', LogisticRegression())
])

pipeline.fit(X_train, y_train)

9. ColumnTransformer

Apply different preprocessing steps to different columns:


from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder

preprocessor = ColumnTransformer(
    transformers=[
        ('num', StandardScaler(), [0, 1]),
        ('cat', OneHotEncoder(), [2])
    ])

10. Summary

  • Preprocessing is crucial for model accuracy and performance.
  • Scikit-learn offers a modular and unified interface for all preprocessing steps.
  • Always preprocess training and testing data in the same way.
