Data Cleaning Techniques in Pandas

Data cleaning is a crucial step in any data analysis workflow. Pandas offers a variety of powerful tools to identify, handle, and clean messy or inconsistent data.

Handling Missing Data

Missing values can affect analysis results. Pandas provides multiple ways to detect and handle them.

Detect Missing Values

df.isnull()   # Returns a DataFrame of booleans indicating missing values
df.notnull()  # Opposite of isnull()

Drop Missing Values

Remove rows or columns containing missing data.

df.dropna()               # Drops rows with any missing values
df.dropna(axis=1)          # Drops columns with any missing values
df.dropna(thresh=2)        # Drops rows with less than 2 non-NA values

Fill Missing Values

Replace missing values with a specific value or strategy.

df.fillna(0)                       # Replace all NaNs with 0
df['column'].fillna(df['column'].mean(), inplace=True)  # Fill NaNs in a column with mean
df.fillna(method='ffill')           # Forward fill (propagate last valid observation)

Removing Duplicates

Duplicate rows can distort analysis. Remove duplicates with:

df.duplicated()    # Returns boolean Series indicating duplicates
df.drop_duplicates(inplace=True)   # Removes duplicate rows

Data Type Conversion

Ensure columns have appropriate data types for analysis and reduce memory usage.

df['column'] = df['column'].astype('int')        # Convert to integer
df['date'] = pd.to_datetime(df['date'])            # Convert to datetime

String Manipulation

Clean textual data with string methods:

df['column'] = df['column'].str.strip()       # Remove leading/trailing spaces
df['column'] = df['column'].str.lower()         # Convert to lowercase
df['column'] = df['column'].str.replace('old', 'new')  # Replace substrings

Replacing Values

Replace specific values using replace():

df.replace({'old_value': 'new_value'}, inplace=True)

Renaming Columns

Rename columns for clarity:

df.rename(columns={'old_name': 'new_name'}, inplace=True)

Example: Cleaning a Dataset

import pandas as pd

data = {
  'Name': ['Alice', 'Bob', None, 'David', 'Eve', 'Frank', 'Bob'],
  'Age': [25, 30, 22, None, 28, 33, 30],
  'Salary': [50000, None, 48000, 52000, None, 61000, None],
  'Department': ['HR', 'IT', 'IT', 'HR', 'Finance', 'Finance', 'IT']
}

df = pd.DataFrame(data)

# Drop rows where 'Name' is missing
df = df.dropna(subset=['Name'])

# Fill missing Age with mean
df['Age'].fillna(df['Age'].mean(), inplace=True)

# Fill missing Salary with 0
df['Salary'].fillna(0, inplace=True)

# Remove duplicate rows
df.drop_duplicates(inplace=True)

print(df)

Summary

Effective data cleaning improves the quality of your dataset, which in turn leads to more accurate and reliable analysis. Pandas provides versatile tools for identifying and fixing common data issues.

Note: Always inspect your data before and after cleaning to ensure the intended changes were made successfully.
