Performing Data Manipulation with Pandas

Pandas is a powerful Python library for data manipulation and analysis. It provides flexible tools to clean, transform, filter, and aggregate data efficiently.

1. Importing Pandas

import pandas as pd

2. Loading Data

Pandas can read data from various formats like CSV, Excel, JSON, SQL, etc.

# Read CSV file
df = pd.read_csv('data.csv')

# Read Excel file
df_excel = pd.read_excel('data.xlsx')

3. Viewing Data

df.head()       # View first 5 rows
df.tail(10)     # View last 10 rows
df.info()       # Summary of dataframe
df.describe()   # Statistical summary of numeric columns

4. Selecting Data

  • df['column_name'] - Select a single column (returns a Series)
  • df[['col1', 'col2']] - Select multiple columns (returns a DataFrame)
  • df.loc[row_label] - Select rows by label
  • df.iloc[row_index] - Select rows by integer position

5. Filtering Data

You can filter rows based on conditions.

# Select rows where Age > 30
filtered_df = df[df['Age'] > 30]

# Select rows where City is 'New York'
ny_df = df[df['City'] == 'New York']

6. Adding and Modifying Columns

# Add a new column
df['Salary'] = [50000, 60000, 70000, 80000]

# Modify an existing column
df['Age'] = df['Age'] + 1  # Increase age by 1 year

7. Handling Missing Data

  • df.isnull() - Detect missing values
  • df.dropna() - Remove rows with missing values
  • df.fillna(value) - Replace missing values
# Replace missing values with 0
df.fillna(0, inplace=True)

8. Sorting Data

# Sort by Age ascending
df_sorted = df.sort_values(by='Age')

# Sort by Salary descending
df_sorted = df.sort_values(by='Salary', ascending=False)

9. Grouping and Aggregation

Group data and calculate summary statistics.

# Group by City and calculate mean age
grouped = df.groupby('City')['Age'].mean()

# Multiple aggregation functions
agg = df.groupby('City').agg({
  'Age': ['mean', 'max'],
  'Salary': 'sum'
})

10. Merging and Joining DataFrames

Combine multiple DataFrames.

# Merge two DataFrames on a common column
merged_df = pd.merge(df1, df2, on='EmployeeID')

# Join based on index
joined_df = df1.join(df2, how='inner')

Summary

  • Pandas offers rich functionality for loading, viewing, selecting, filtering, modifying, and aggregating data.
  • Mastering these operations helps in effective data preprocessing and analysis.
