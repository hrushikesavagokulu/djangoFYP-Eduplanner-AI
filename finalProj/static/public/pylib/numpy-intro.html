Introduction to NumPy

NumPy (Numerical Python) is a fundamental package for scientific computing with Python. It provides support for large, multi-dimensional arrays and matrices, along with a large collection of high-level mathematical functions to operate on these arrays efficiently.

Why use NumPy?

  • Efficient storage and manipulation of numerical data.
  • Provides vectorized operations that are faster than Python loops.
  • Essential for data science, machine learning, and scientific computing.
  • Foundation for libraries like Pandas, SciPy, scikit-learn, and others.

Installing NumPy

Install NumPy using pip:

pip install numpy

Importing NumPy

Import the library using the common alias np:

import numpy as np

Creating NumPy Arrays

NumPy arrays are the core data structure:

# Create a 1D array from a Python list
arr = np.array([1, 2, 3, 4, 5])

# Create a 2D array (matrix)
mat = np.array([[1, 2], [3, 4]])

Array Attributes

Commonly used attributes to understand array structure:

  • arr.shape: Returns the dimensions (rows, columns).
  • arr.size: Total number of elements.
  • arr.dtype: Data type of elements.
  • arr.ndim: Number of dimensions.
print(arr.shape)  # Output: (5,)
print(mat.shape)  # Output: (2, 2)
print(arr.size)   # Output: 5
print(arr.dtype)  # Output: int64 (or similar)
print(arr.ndim)   # Output: 1

Why NumPy Arrays instead of Python Lists?

NumPy arrays consume less memory and provide better performance:

  • Support for vectorized operations.
  • Broadcasting capabilities for arithmetic operations.
  • Convenient mathematical and statistical functions.

Basic Array Operations

You can perform arithmetic operations on entire arrays:

arr = np.array([1, 2, 3])
print(arr + 10)   # [11 12 13]
print(arr * 2)    # [2 4 6]

Summary

NumPy is essential for anyone doing numerical computations in Python. It allows fast, memory-efficient operations on large datasets and forms the foundation of the Python data science ecosystem.
