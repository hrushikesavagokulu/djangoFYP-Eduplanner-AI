Classification and Regression Models in Scikit-learn

Scikit-learn provides a wide variety of machine learning models for classification and regression. These models are simple to use, follow a consistent API, and are ideal for both beginners and advanced users.

1. Classification Models

Classification is the task of predicting a discrete class label. Here are some popular classifiers in scikit-learn:

  • LogisticRegression
  • KNeighborsClassifier
  • DecisionTreeClassifier
  • RandomForestClassifier
  • SVC (Support Vector Classifier)

Example: Logistic Regression

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# Load dataset
X, y = load_iris(return_X_y=True)

# Split into train and test
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Train classifier
model = LogisticRegression(max_iter=200)
model.fit(X_train, y_train)

# Predict and evaluate
predictions = model.predict(X_test)
print("Accuracy:", accuracy_score(y_test, predictions))

2. Regression Models

Regression is the task of predicting a continuous numerical value. Some common regression models:

  • LinearRegression
  • Ridge and Lasso Regression
  • DecisionTreeRegressor
  • RandomForestRegressor
  • SVR (Support Vector Regressor)

Example: Linear Regression

from sklearn.datasets import fetch_california_housing
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# Load data
data = fetch_california_housing()
X, y = data.data, data.target

# Train-test split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

# Fit model
regressor = LinearRegression()
regressor.fit(X_train, y_train)

# Predict and evaluate
y_pred = regressor.predict(X_test)
print("MSE:", mean_squared_error(y_test, y_pred))

3. Common API Across Models

All models in Scikit-learn use a consistent pattern:

model = ModelClass()
model.fit(X_train, y_train)
predictions = model.predict(X_test)
Note: Some models like LogisticRegression require feature scaling for optimal performance.

4. Choosing the Right Model

  • Logistic Regression: Great for linear binary classification.
  • Random Forest: Powerful and easy-to-use for both classification and regression.
  • KNN: Simple but slow with large datasets.
  • SVC/SVR: Powerful with proper kernel and parameters, but requires tuning.

5. Summary

Scikit-learn simplifies working with many machine learning models using a unified API. Try different models and compare results using metrics like accuracy, precision, recall (for classification), and MSE or R2 (for regression).
