Function Pointers

Function pointers in C are pointers that point to the address of a function, allowing you to store and call functions dynamically. They are useful for callback mechanisms, implementing function tables, and writing flexible APIs.

Declaring a Function Pointer

The syntax for declaring a function pointer:

return_type (*pointer_name)(parameter_types);

Example

int add(int a, int b) {
    return a + b;
}

// Declare a function pointer that points to a function taking two ints and returning int
int (*func_ptr)(int, int);

// Assign address of add to the function pointer
func_ptr = &add;

// Call the function via the pointer
int result = func_ptr(5, 3);  // result = 8

Using Function Pointers as Callbacks

You can pass function pointers as arguments to other functions to implement callbacks:

void greet(void (*printer)(const char *)) {
    printer("Hello from greet!");
}

void printToConsole(const char *msg) {
    printf("%s\n", msg);
}

int main() {
    greet(printToConsole);  // pass function pointer as argument
    return 0;
}

Why Use Function Pointers?

  • To invoke different functions dynamically at runtime.
  • Implement callback functions in libraries and APIs.
  • Create tables of functions (like jump tables or dispatch tables).
Note: When assigning a function to a function pointer, the & operator is optional. Similarly, when calling through the pointer, parentheses are necessary: func_ptr(args).
