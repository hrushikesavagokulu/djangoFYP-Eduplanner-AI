While Loops

The while loop in C is a control flow statement that allows code to be executed repeatedly based on a given Boolean condition. The loop continues to execute as long as the condition evaluates to true.

Syntax

while (condition) {
    // statements to execute
}

Here, condition is an expression that is evaluated before each iteration. If it evaluates to true (non-zero), the statements inside the loop execute. When the condition becomes false (zero), the loop terminates, and control passes to the next statement after the loop.

Flowchart

In a while loop:

  • The condition is checked first.
  • If true, the loop body executes.
  • After the body, the condition is checked again.
  • This continues until the condition is false.

Example: Counting from 1 to 5

#include <stdio.h>

int main() {
    int count = 1;
    
    while (count <= 5) {
        printf("Count is %d\n", count);
        count++;  // increment count by 1
    }
    
    return 0;
}

Output:

Count is 1
Count is 2
Count is 3
Count is 4
Count is 5

Key Points

  • The condition is evaluated before the loop body executes. This means if the condition is false initially, the loop body will not execute even once.
  • If the condition never becomes false, the loop will continue forever (infinite loop).
  • Use a variable or expression inside the loop to eventually make the condition false, otherwise the loop will not terminate.
Note: If you want the loop body to execute at least once regardless of the condition, use a do-while loop instead.

Common Mistake: Forgetting to Update the Loop Variable

If you forget to increment or update the variable that controls the loop condition, your program may enter an infinite loop. For example:

#include <stdio.h>

int main() {
    int count = 1;
    
    while (count <= 5) {
        printf("Count is %d\n", count);
        // Missing count++ here causes infinite loop
    }
    
    return 0;
}
Warning: This will cause the loop to run forever because count never changes.

Summary

  • while loops repeat as long as a condition is true.
  • Condition is checked before executing the loop body.
  • Useful when the number of iterations is not known beforehand.
  • Always ensure the loop will terminate by modifying the loop condition inside the loop.
