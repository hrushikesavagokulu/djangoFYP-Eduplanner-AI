Syntax

In programming, syntax refers to the set of rules that defines the structure and format of valid statements in a language. Just like grammar in natural languages, syntax ensures that the code is written in a way the compiler or interpreter can understand.

Why Syntax Matters

  • Correctness: Proper syntax is essential for the program to compile and run.
  • Readability: Following syntax rules makes code easier to read and maintain.
  • Error Detection: Syntax errors are caught early by compilers or interpreters, helping prevent bugs.

Basic Syntax Rules in C

  • Every statement ends with a semicolon ;.
  • Curly braces { } group statements into blocks.
  • Comments can be single-line (// comment) or multi-line (/* comment */).
  • Variable names (identifiers) must start with a letter or underscore and contain letters, digits, or underscores.
  • C is case-sensitive (Variable and variable are different).

Example of Basic Syntax

#include <stdio.h>

int main() {
    int number = 5;             // Declare and initialize variable
    printf("Number: %d\n", number);  // Print the value
    return 0;                   // Return success status
}

Common Syntax Errors

  • Missing semicolon.
  • Mismatched or missing braces { }.
  • Incorrect use of keywords.
  • Using undeclared variables.

Tips for Writing Correct Syntax

  • Indent code properly to visually group blocks.
  • Use an editor or IDE with syntax highlighting and error detection.
  • Break code into smaller functions for clarity.
