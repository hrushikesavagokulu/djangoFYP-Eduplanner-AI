Recursion in C

Recursion is a programming technique where a function calls itself directly or indirectly to solve a problem. It is especially useful for problems that can be broken down into smaller, similar subproblems.

How Recursion Works

A recursive function generally has two main parts:

  • Base Case: This condition stops the recursion by not making any further recursive calls.
  • Recursive Case: This is where the function calls itself with a smaller or simpler input, moving toward the base case.
Note: Without a proper base case, recursion will lead to infinite calls and eventually cause a stack overflow error.

Syntax of a Recursive Function

return_type function_name(parameters) {
    if (base_condition) {
        // base case: stop recursion
        return some_value;
    } else {
        // recursive case: function calls itself
        return function_name(smaller_parameters);
    }
}

Example: Factorial Calculation

The factorial of a non-negative integer n is defined as:

  • 0! = 1 (base case)
  • n! = n × (n-1)! for n > 0
#include <stdio.h>

int factorial(int n) {
    if (n == 0) {
        return 1;  // Base case
    } else {
        return n * factorial(n - 1);  // Recursive call
    }
}

int main() {
    int num = 5;
    printf("Factorial of %d is %d\n", num, factorial(num));
    return 0;
}

How This Works:

  • factorial(5) calls factorial(4)
  • factorial(4) calls factorial(3), and so on...
  • When factorial(0) is reached, it returns 1 (base case)
  • Then, the calls return one by one, multiplying the results back up the call stack

Common Uses of Recursion

  • Mathematical computations (factorial, Fibonacci series)
  • Tree and graph traversals
  • Divide and conquer algorithms (merge sort, quick sort)
  • Backtracking problems (e.g., puzzles, maze solving)

Troubleshooting Recursion

  • Always ensure there is a reachable base case.
  • Check that each recursive call progresses toward the base case.
  • Be cautious of large input sizes; deep recursion may cause stack overflow.
