Do While Loops

The do...while loop in C is a control flow statement that executes a block of code at least once, and then repeatedly executes it as long as a specified condition is true.

Syntax

do {
    // code to execute
} while (condition);

How It Works

  • The code block inside the do runs first.
  • After executing the block, the condition is evaluated.
  • If the condition is true, the loop repeats the block.
  • If the condition is false, the loop terminates.

Key Difference from while Loop

Unlike the while loop, which tests the condition before running the code block, the do...while loop always runs the code block at least once, regardless of the condition.

Example

#include <stdio.h>

int main() {
    int count = 1;

    do {
        printf("Count is %d\n", count);
        count++;
    } while (count <= 5);

    return 0;
}

Output:

Count is 1
Count is 2
Count is 3
Count is 4
Count is 5

Use Cases for do...while Loop

  • When you want to ensure the loop body executes at least once.
  • When the loop condition depends on the result of the code block.
  • Input validation scenarios where you want to prompt the user at least once.
Note: Remember the semicolon ; at the end of the while(condition); line — it is mandatory.
