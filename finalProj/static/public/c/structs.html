Structs in C

A struct (short for structure) in C is a user-defined data type that groups together variables of different types under a single name. It allows you to combine related data of various types into one cohesive unit, making it easier to manage complex data.

Why Use Structs?

  • To organize related data under one variable.
  • To represent complex objects like records, points, students, etc.
  • To improve code readability and maintainability.

Syntax

struct StructName {
    dataType member1;
    dataType member2;
    ...
};

Here, StructName is the name of the structure type, and the members are variables inside the structure.

Example: Defining and Using a Struct

#include <stdio.h>

struct Point {
    int x;
    int y;
};

int main() {
    struct Point p1;       // Declare a struct variable p1 of type Point
    p1.x = 10;             // Access and assign value to member x
    p1.y = 20;             // Access and assign value to member y

    printf("Point coordinates: (%d, %d)\n", p1.x, p1.y);
    return 0;
}

Declaring Struct Variables

  • You can declare variables of a struct type like struct Point p1;
  • Multiple variables can be declared at once: struct Point p2, p3;
  • To avoid writing struct repeatedly, use typedef:
typedef struct {
    int x;
    int y;
} Point;

Point p1, p2;

Accessing Members

  • Use the dot operator . to access members of a struct variable, e.g., p1.x
  • For pointers to structs, use the arrow operator ->, e.g., pPtr->x

Example: Using Pointer to Struct

Point p1 = {5, 10};
Point *pPtr = &p1;

printf("x = %d, y = %d\n", pPtr->x, pPtr->y);

Initializing Structs

  • Initialize at declaration: struct Point p1 = {1, 2};
  • Partial initialization sets remaining members to zero.

Nested Structs

Structs can contain other structs as members:

struct Date {
    int day;
    int month;
    int year;
};

struct Person {
    char name[50];
    struct Date birthday;
};

Use Case Example

struct Student {
    int id;
    char name[30];
    float marks;
};

struct Student s1 = {101, "Alice", 89.5};
printf("ID: %d, Name: %s, Marks: %.2f\n", s1.id, s1.name, s1.marks);

Important Notes

  • Structs can contain variables of any data type, including arrays, pointers, and other structs.
  • Memory size of a struct is at least the sum of sizes of its members, but may include padding for alignment.
  • Structs provide a way to model real-world entities in programs.
