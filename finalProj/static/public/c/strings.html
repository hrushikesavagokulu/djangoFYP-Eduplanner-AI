Strings in C

In C, strings are arrays of characters terminated by a special null character '\0'. They are used to represent text.

What is a String?

A string is a sequence of characters stored in contiguous memory locations ending with a null character '\0' which marks the end of the string.

Declaring Strings

  • char str[20]; — Declares a character array that can hold up to 19 characters + the terminating null character.
  • char str[] = "Hello"; — Automatically sized array initialized with string "Hello".

String Initialization Examples

char name[10] = "Alice";      // 'A' 'l' 'i' 'c' 'e' '\0'
char greeting[] = "Hello!";    // size is 7 (including '\0')

Important Points

  • The last character of every string literal is always '\0' (null terminator).
  • Strings are stored as arrays of characters, so indexing works as with arrays.
  • You must ensure the array is large enough to hold the string plus the terminating '\0'.

Accessing Characters

You can access characters of a string like an array:

char str[] = "Hello";
printf("%c\n", str[0]);  // Output: H
printf("%c\n", str[4]);  // Output: o

Reading Strings

Use scanf or fgets to read strings from user input:

char input[50];
printf("Enter your name: ");
scanf("%49s", input);   // Reads a word (no spaces)

OR

fgets(input, 50, stdin);  // Reads a line (including spaces)

Common String Functions (from <string.h>)

  • strlen(str) — Returns length of string excluding '\0'.
  • strcpy(dest, src) — Copies string from src to dest.
  • strcat(dest, src) — Appends src to end of dest.
  • strcmp(str1, str2) — Compares two strings; returns 0 if equal.

Example Using String Functions

#include <stdio.h>
#include <string.h>

int main() {
    char str1[20] = "Hello";
    char str2[] = "World";
    char str3[40];

    printf("Length of str1: %lu\n", strlen(str1));

    strcpy(str3, str1);
    strcat(str3, " ");
    strcat(str3, str2);

    printf("Concatenated string: %s\n", str3);

    if (strcmp(str1, str2) == 0) {
        printf("Strings are equal.\n");
    } else {
        printf("Strings are different.\n");
    }

    return 0;
}

Notes

  • Always ensure the destination array is large enough to hold the result in strcpy and strcat.
  • scanf("%s", str) stops reading input at the first whitespace.
  • fgets() reads the entire line including spaces but stores the newline character '\n' if space permits.
  • Strings in C are mutable if declared as character arrays but string literals (e.g., char *str = "Hello";) should not be modified.
