Arrays in C

In C programming, an array is a data structure that can store a fixed-size sequence of elements of the same type. Arrays are used to organize data so that related values can be easily accessed and manipulated.

1. Why Use Arrays?

  • To store multiple values in a single variable.
  • Efficient access via indexing.
  • Better organization of related data (e.g., marks of students, temperatures, etc.).

2. Declaration and Initialization

Declaration

int numbers[5]; // declares an array of 5 integers

Initialization

int a[5] = {10, 20, 30, 40, 50};

If fewer values are provided, the rest are set to 0:

int a[5] = {10, 20}; // becomes {10, 20, 0, 0, 0}

3. Accessing Array Elements

Each element is accessed using its index (starting from 0):

printf("%d", a[2]); // prints 30

4. Array Types

i. One-dimensional Arrays

Used for storing lists or single rows of data.

float prices[10];

ii. Two-dimensional Arrays

Used for matrices or tables.

int matrix[3][4];

iii. Multidimensional Arrays

Less common; useful for complex data like 3D maps.

char cube[3][4][5];

5. Input/Output of Arrays

Input Example


for (int i = 0; i < 5; i++) {
  scanf("%d", &a[i]);
}

Output Example


for (int i = 0; i < 5; i++) {
  printf("%d ", a[i]);
}

6. Common Array Operations

  • Traversing
  • Searching (Linear/Binary)
  • Sorting (Bubble, Selection, etc.)
  • Reversing

7. Example: Find Maximum in Array


int max = a[0];
for (int i = 1; i < 5; i++) {
  if (a[i] > max)
    max = a[i];
}
printf("Maximum: %d", max);

8. Array Memory Layout

Note: Arrays are stored in contiguous memory locations. That’s why pointer arithmetic works well with arrays.

Example:


int a[3] = {5, 10, 15};
printf("%p", &a[0]); // Address of first element
printf("%p", &a[1]); // Next address (usually +4 bytes)

9. Array and Functions

Passing Array to Function


void display(int arr[], int size) {
  for (int i = 0; i < size; i++)
    printf("%d ", arr[i]);
}

Calling Function


int nums[5] = {1,2,3,4,5};
display(nums, 5);

10. Strings as Character Arrays


char name[10] = "Alice";
printf("%s", name); // prints Alice
Warning: Make sure your character arrays are large enough to include the null terminator \0 at the end of strings.

11. Limitations of Arrays

  • Fixed size (can’t grow/shrink dynamically)
  • No bounds checking (C doesn’t warn if you go out of bounds)

12. Best Practices

  • Always initialize your arrays.
  • Avoid magic numbers – use #define SIZE 100.
  • Be cautious with bounds and overflows.
