Dynamic Memory

Dynamic Memory in C

Dynamic memory allocation allows you to request memory at runtime, which is useful when the amount of memory required is not known at compile time.

Why Use Dynamic Memory?

  • Allocate memory as needed during program execution.
  • Create data structures like linked lists, trees, or resizable arrays.
  • Manage memory efficiently for variable-sized data.

Key Functions for Dynamic Memory

C provides four main functions in <stdlib.h> for managing dynamic memory:

  • malloc(size_t size): Allocates size bytes and returns a pointer to the allocated memory.
  • calloc(size_t nitems, size_t size): Allocates memory for an array of nitems elements, each of size bytes, and initializes all bytes to zero.
  • realloc(void *ptr, size_t size): Changes the size of the memory block pointed to by ptr to size bytes.
  • free(void *ptr): Frees the memory previously allocated by malloc, calloc, or realloc.

Example: Using malloc and free

#include <stdio.h>
#include <stdlib.h>

int main() {
    int *ptr;
    int n = 5;

    // Allocate memory for 5 integers
    ptr = (int *)malloc(n * sizeof(int));
    if (ptr == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    // Initialize and print the values
    for (int i = 0; i < n; i++) {
        ptr[i] = i * 10;
        printf("ptr[%d] = %d\n", i, ptr[i]);
    }

    // Free the allocated memory
    free(ptr);

    return 0;
}

Notes on Dynamic Memory

  • Always check if the memory allocation succeeded by verifying the returned pointer is not NULL.
  • Memory allocated with malloc, calloc, or realloc must be freed using free to avoid memory leaks.
  • Using uninitialized pointers or accessing freed memory causes undefined behavior.
Note: Casting the result of malloc is not required in C but often done for clarity or compatibility with C++.

Example: Using calloc and realloc

#include <stdio.h>
#include <stdlib.h>

int main() {
    int *arr;
    int n = 3;

    // Allocate and initialize memory for 3 integers
    arr = (int *)calloc(n, sizeof(int));
    if (arr == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    // Print initialized values (all zeros)
    for (int i = 0; i < n; i++) {
        printf("arr[%d] = %d\n", i, arr[i]);
    }

    // Resize array to hold 5 integers
    arr = (int *)realloc(arr, 5 * sizeof(int));
    if (arr == NULL) {
        printf("Reallocation failed\n");
        return 1;
    }

    // Initialize new elements
    for (int i = n; i < 5; i++) {
        arr[i] = i * 10;
    }

    printf("After realloc:\n");
    for (int i = 0; i < 5; i++) {
        printf("arr[%d] = %d\n", i, arr[i]);
    }

    free(arr);

    return 0;
}
