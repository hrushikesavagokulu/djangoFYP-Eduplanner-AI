Loop Control

In C programming, controlling loops is essential to manage the flow of iteration. The main loop control statements are break, continue, and goto. These allow you to alter the normal execution sequence of loops like for, while, and do-while.

1. The break Statement

The break statement immediately terminates the innermost loop or switch statement and transfers control to the statement following the loop.

for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;  // exit loop when i equals 5
    }
    printf("%d\n", i);
}

2. The continue Statement

The continue statement skips the remaining statements inside the current iteration and moves control to the next iteration of the loop.

for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;  // skip even numbers
    }
    printf("%d\n", i);
}

3. The goto Statement

The goto statement jumps to a labeled statement elsewhere in the code. Its use is generally discouraged because it can make code hard to read and maintain, but it can sometimes simplify complex control flows.

int i = 0;
start_loop:
if (i >= 10) {
    goto end_loop;
}
printf("%d\n", i);
i++;
goto start_loop;
end_loop:
printf("Loop ended\n");
Note: Use break and continue for clearer and safer loop control. Avoid goto unless absolutely necessary.
