For Loops

The for loop is a control flow statement that allows you to execute a block of code repeatedly with a specified number of iterations.

Syntax

for (initialization; condition; update) {
    // statements to be executed
}
  • initialization: Sets the starting value, executed once at the beginning.
  • condition: Evaluated before each iteration. If true, the loop body executes; if false, the loop ends.
  • update: Executed after each iteration, usually used to increment or decrement the loop counter.

Example: Print Numbers from 1 to 5

#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 5; i++) {
        printf("%d\n", i);
    }
    return 0;
}

Explanation:

  • i = 1; initializes the loop counter.
  • i <= 5; is the loop continuation condition.
  • i++; increments the counter after each iteration.
  • The body prints the current value of i.
Note: The for loop is often used when the number of iterations is known beforehand.

Nested For Loops

You can use one for loop inside another to iterate through multi-dimensional data.

Example: Print a 3x3 matrix of stars

#include <stdio.h>

int main() {
    int row, col;
    for (row = 1; row <= 3; row++) {
        for (col = 1; col <= 3; col++) {
            printf("* ");
        }
        printf("\n");
    }
    return 0;
}
