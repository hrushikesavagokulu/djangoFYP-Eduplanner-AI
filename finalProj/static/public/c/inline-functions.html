Inline Functions

In C programming, an inline function is a special function that the compiler attempts to expand at the point of each call instead of performing a regular function call. This can improve performance by eliminating the overhead of function calls, especially for small, frequently called functions.

Why Use Inline Functions?

  • Reduces function call overhead.
  • Can increase execution speed for small functions.
  • Improves code readability compared to macros.

Syntax

inline return_type function_name(parameter_list) {
    // function body
}

Example

inline int square(int x) {
    return x * x;
}

int main() {
    int result = square(5);
    printf("Square of 5 is %d\n", result);
    return 0;
}
Note: The inline keyword is a request to the compiler, not a command. The compiler may ignore it if inlining is not possible or not beneficial.

Comparison with Macros

  • Inline functions are type-safe and scoped.
  • Macros perform simple text substitution and can cause unexpected side effects.
