Const and Volatile Qualifiers in C

The const and volatile keywords are type qualifiers in C that modify the behavior of variables in different ways.

The const Qualifier

The const qualifier indicates that a variable’s value cannot be changed after initialization.

  • Trying to modify a const variable results in a compile-time error.
  • It provides safety by preventing accidental modification.
  • It allows the compiler to optimize the code better.

Example:

const int maxUsers = 100;
maxUsers = 200;  // Error: assignment of read-only variable

The volatile Qualifier

The volatile qualifier tells the compiler that the value of a variable can change at any time without any action by the code itself. This is common in:

  • Hardware registers in embedded programming
  • Variables modified by interrupts or signal handlers
  • Variables shared between multiple threads

Without volatile, the compiler might optimize access to the variable by caching it in a register and not rereading it, which could cause incorrect behavior.

Example:

volatile int flag = 0;

// Some other thread or hardware changes flag asynchronously
while(flag == 0) {
  // wait until flag changes
}

Combining const and volatile

Sometimes a variable can be both const and volatile. This means the program itself should not modify it, but the value can change unexpectedly from outside the program's control (e.g., hardware registers).

const volatile int statusRegister = 0x4000;

Summary

Qualifier Purpose Example
const Prevent modification of variable after initialization const int x = 10;
