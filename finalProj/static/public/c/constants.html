Constants in C

Constants are fixed values that do not change during the execution of a program. Using constants makes your code more readable and easier to maintain.

Types of Constants

  • Literal Constants: Fixed values written directly in the code (e.g., 10, 3.14, 'A').
  • Defined Constants: Constants defined using #define preprocessor directive.
  • Constant Variables: Variables declared with the const keyword that cannot be modified after initialization.

1. Literal Constants

These are values directly embedded in your code:

  • 42 — integer literal
  • 3.14159 — floating-point literal
  • 'Z' — character literal
  • "Hello" — string literal

2. #define Constants

The #define directive defines symbolic constants. These constants are replaced by the preprocessor before compilation.

#define PI 3.14159
#define MAX_USERS 100
#define GREETING "Welcome to the program!"

Usage example:

printf("Value of PI is %f\n", PI);
printf("%s\n", GREETING);
Note: #define constants do not consume memory and are replaced inline during preprocessing.

3. const Variables

You can declare variables as constant using the const keyword. These variables must be initialized at declaration and cannot be changed afterwards.

const int DAYS_IN_WEEK = 7;
const float GRAVITY = 9.8f;
const char NEWLINE = '\n';

Attempting to modify a const variable will result in a compile-time error:

DAYS_IN_WEEK = 8; // Error!
Warning: Unlike #define, const variables have a type and can be debugged more easily.

4. Enumerated Constants (enum)

The enum keyword defines a set of named integer constants, making code easier to read.

enum Weekday {
  Sunday,    // 0
  Monday,    // 1
  Tuesday,   // 2
  Wednesday, // 3
  Thursday,  // 4
  Friday,    // 5
  Saturday   // 6
};

enum Weekday today = Wednesday;

You can also assign custom values:

enum Weekday {
  Sunday = 1,
  Monday,
  Tuesday,
  Wednesday,
  Thursday,
  Friday,
  Saturday
};

Why Use Constants?

  • Make code more readable and meaningful
  • Prevent accidental modification of values
  • Facilitate easy updates by changing the value in one place

Summary
