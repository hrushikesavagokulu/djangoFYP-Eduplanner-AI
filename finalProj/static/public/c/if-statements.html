If Statements

The if statement is one of the fundamental control structures in C programming. It allows you to execute a block of code only if a specified condition is true.

Basic Syntax

if (condition) {
    // code to execute if condition is true
}

Example

int x = 10;

if (x > 5) {
    printf("x is greater than 5\n");
}

Using else

You can add an else block to execute code when the condition is false.

if (x > 5) {
    printf("x is greater than 5\n");
} else {
    printf("x is not greater than 5\n");
}

Using else if

To check multiple conditions, use else if:

if (x > 10) {
    printf("x is greater than 10\n");
} else if (x == 10) {
    printf("x is equal to 10\n");
} else {
    printf("x is less than 10\n");
}

Important Notes

  • The condition inside the if parentheses must evaluate to true (non-zero) or false (zero).
  • Curly braces { } define the code block. For a single statement, braces are optional but recommended for clarity.
  • Conditions can use comparison operators like ==, !=, <, >, <=, >=.
Note: Always use == to compare values. Using a single = is assignment and can cause bugs.
