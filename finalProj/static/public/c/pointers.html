Pointers in C

Pointers are one of the most powerful and important features of the C programming language. A pointer is a variable that stores the memory address of another variable. Pointers allow you to directly access and manipulate memory, making C very flexible and efficient.

Why Use Pointers?

  • To access and modify variables directly in memory.
  • To dynamically allocate memory.
  • To work efficiently with arrays and strings.
  • To enable functions to modify variables passed by reference.

Pointer Syntax

Declaring a Pointer

Use the * operator to declare a pointer to a specific type.

int *ptr;        // pointer to an int
char *cptr;       // pointer to a char
float *fptr;      // pointer to a float

Assigning Address to a Pointer

Use the address-of operator & to get the address of a variable.

int x = 10;
int *ptr = &x;    // ptr now holds the address of x

Dereferencing a Pointer

The * operator is used to access the value stored at the address the pointer holds.

printf("Value of x: %d\n", *ptr);   // prints 10

*ptr = 20;        // changes the value of x to 20
printf("New value of x: %d\n", x);    // prints 20

Pointer Arithmetic

When pointers point to elements in arrays, you can perform arithmetic on them:

  • ptr + 1 moves the pointer to the next element of the pointer's type.
  • ptr - 1 moves it to the previous element.
  • Incrementing/decrementing pointers is useful for traversing arrays.
int arr[] = {10, 20, 30};
int *ptr = arr;

printf("%d\n", *ptr);       // 10
printf("%d\n", *(ptr + 1)); // 20
ptr++;
printf("%d\n", *ptr);       // 20

Important Notes

  • Always initialize pointers before use to avoid undefined behavior.
  • Pointer type must match the type of data they point to for proper dereferencing.
  • Use NULL to indicate a pointer that points to nothing.
  • Be cautious with pointer arithmetic to avoid accessing invalid memory.
Note: Using pointers incorrectly can lead to serious bugs such as segmentation faults or memory corruption.
