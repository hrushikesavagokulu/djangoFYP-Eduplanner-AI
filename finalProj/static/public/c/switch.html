Switch Statement

The switch statement in C provides a way to select one of many code blocks to execute based on the value of a variable or expression. It is an alternative to using multiple if-else conditions and is especially useful when dealing with multiple discrete values.

Syntax

switch (expression) {
  case constant1:
    // statements
    break;
  case constant2:
    // statements
    break;
  ...
  default:
    // statements
}

How It Works

  • The expression is evaluated once.
  • Its value is compared with each case constant.
  • If a match is found, the corresponding statements execute.
  • The break statement stops further execution and exits the switch.
  • If no case matches, the default block executes (optional).

Example

#include <stdio.h>

int main() {
    int day = 3;
    switch(day) {
        case 1:
            printf("Monday\n");
            break;
        case 2:
            printf("Tuesday\n");
            break;
        case 3:
            printf("Wednesday\n");
            break;
        default:
            printf("Invalid day\n");
    }
    return 0;
}

Important Points

  • case labels must be constant expressions.
  • Omitting break causes fall-through, meaning execution continues into the next case.
  • default is optional but good for handling unexpected values.
  • Only integral types (int, char, enums) are allowed in switch expressions.

Fall-Through Example

int n = 2;
switch(n) {
    case 1:
        printf("One\n");
    case 2:
        printf("Two\n");
    case 3:
        printf("Three\n");
        break;
}

Output:

Two
Three

Since break is missing after case 2, execution falls through to case 3.
