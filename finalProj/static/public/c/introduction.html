Introduction to C Programming

C is one of the most powerful and widely used programming languages. It was developed in the early 1970s by Dennis Ritchie at Bell Labs and has since become the foundation of many modern programming languages such as C++, Java, and Python.

Why Learn C?

  • Foundation Language: Many modern languages borrow syntax and concepts from C.
  • Efficient and Fast: C provides low-level access to memory and is compiled to very efficient machine code.
  • Portability: C programs can be compiled and run on many different computer systems.
  • Wide Application: Used in system programming, embedded devices, operating systems (like Unix/Linux), and game development.

Basic Structure of a C Program

A typical C program looks like this:

#include <stdio.h>

int main() {
    // This is the main function - program execution starts here
    printf("Hello, World!\n");
    return 0;
}

Explanation:

  • #include <stdio.h> - This line tells the compiler to include the Standard Input Output library which contains functions like printf.
  • int main() - The main function is the entry point of every C program.
  • printf("Hello, World!\n"); - Prints the text "Hello, World!" to the console.
  • return 0; - Indicates the program finished successfully.
Note: Every C program must have exactly one main function.

How to Compile and Run a C Program

To run C code, you need a compiler. The most popular one is gcc (GNU Compiler Collection).

Here is how you can compile and run the program above:

// Save the code in a file called hello.c
gcc hello.c -o hello    // Compile hello.c to an executable named hello
./hello                 // Run the executable
Warning: Compilation errors are common when starting. Carefully read the error messages and fix issues step by step.
