Standard Input and Output (stdio.h) in C

The stdio.h header file is one of the most essential libraries in C programming. It provides functions for input and output (I/O) operations, such as reading from the keyboard and writing to the screen.

Including stdio.h

To use the standard I/O functions, include the header at the top of your C program:

#include <stdio.h>

Commonly Used Functions in stdio.h

  • printf() - Outputs formatted text to the console.
  • scanf() - Reads formatted input from the keyboard.
  • getchar() - Reads a single character from the keyboard.
  • putchar() - Writes a single character to the console.
  • gets() - Reads a string from the keyboard (unsafe, avoid using).
  • fgets() - Safely reads a string from the keyboard or file.
  • puts() - Writes a string to the console followed by a newline.

Syntax and Examples

printf()

Used to print formatted output.

printf("Hello, World!\n");
printf("Age: %d\n", 25);
printf("Pi approx: %.2f\n", 3.14159);

scanf()

Used to read formatted input from the user.

int age;
printf("Enter your age: ");
scanf("%d", &age);
printf("You entered: %d\n", age);

getchar() and putchar()

Reading and writing single characters.

char ch;
printf("Enter a character: ");
ch = getchar();
printf("You entered: ");
putchar(ch);
printf("\n");

fgets() and puts()

Reading and printing strings safely.

char name[30];
printf("Enter your name: ");
fgets(name, sizeof(name), stdin);  // Reads including spaces
puts("Hello,");
puts(name);  // Prints the name followed by a newline

Important Notes

  • printf format specifiers include: %d (int), %f (float), %c (char), %s (string), and more.
  • scanf requires pointers (use & before variable names) except for strings.
  • gets() is unsafe because it does not prevent buffer overflow; prefer fgets() instead.
  • stdin and stdout are standard streams used by stdio.h.

Example Program

#include <stdio.h>

int main() {
    char name[50];
    int age;

    printf("Enter your name: ");
    fgets(name, sizeof(name), stdin);

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Hello, %sYou are %d years old.\n", name, age);

    return 0;
}
