Formatted I/O in C

Formatted input/output functions provide a way to read and write data with a specific format. The most common functions used for formatted I/O in C are printf() and scanf().

printf()

The printf() function prints formatted output to the console.

Syntax:

int printf(const char *format, ...);

Common Format Specifiers:

  • %d - Integer
  • %f - Floating point number
  • %c - Character
  • %s - String
  • %x - Hexadecimal (lowercase)
  • %p - Pointer address

Example:

int num = 42;
float pi = 3.14159;
printf("Number: %d, Pi: %.2f\n", num, pi);

scanf()

The scanf() function reads formatted input from the user.

Syntax:

int scanf(const char *format, ...);

Example:

int age;
printf("Enter your age: ");
scanf("%d", &age);
printf("You entered: %d\n", age);
Note: When using scanf(), always provide the address of the variable using the & operator except when reading strings with %s.

Advanced Formatting

  • Width specifier: %5d prints integer in a field at least 5 characters wide.
  • Precision specifier: %.3f prints a float with 3 decimal places.
  • Left justification: %-10s left-justifies a string in a 10 character wide field.

Example:

printf("|%10s|\n", "Hello");    // Right justified
printf("|%-10s|\n", "Hello");   // Left justified
