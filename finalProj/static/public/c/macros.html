Memory Management

Memory management in C is a crucial concept that involves the allocation, use, and release of memory during a program's execution. Efficient memory management ensures optimal use of system resources and prevents issues like memory leaks and segmentation faults.

Memory Areas in C

  • Stack: Stores local variables and function call information. It is managed automatically and has limited size.
  • Heap: Used for dynamic memory allocation during runtime. Managed manually by the programmer using functions like malloc and free.
  • Data Segment: Contains global and static variables.
  • Code Segment: Contains the compiled program code.

Dynamic Memory Allocation

C provides several standard library functions to allocate and manage memory dynamically:

  • malloc(size_t size): Allocates size bytes and returns a pointer to the allocated memory.
  • calloc(size_t nmemb, size_t size): Allocates memory for an array of nmemb elements of size bytes each, initialized to zero.
  • realloc(void *ptr, size_t size): Resizes previously allocated memory block pointed by ptr to size bytes.
  • free(void *ptr): Releases the memory previously allocated.

Example of Dynamic Memory Allocation

#include <stdio.h>
#include <stdlib.h>

int main() {
    int *ptr;
    int n, i;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    ptr = (int*) malloc(n * sizeof(int));
    if (ptr == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    printf("Enter %d integers:\n", n);
    for (i = 0; i < n; i++) {
        scanf("%d", &ptr[i]);
    }

    printf("You entered: ");
    for (i = 0; i < n; i++) {
        printf("%d ", ptr[i]);
    }
    printf("\n");

    free(ptr); // Important to free allocated memory

    return 0;
}
Note: Always check the return value of malloc and calloc for NULL to avoid dereferencing invalid pointers. Also, remember to free any dynamically allocated memory to prevent memory leaks.
Warning: Using memory after it has been freed (dangling pointers) or failing to free memory can cause undefined behavior or memory leaks.
