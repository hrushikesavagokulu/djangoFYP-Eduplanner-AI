Pointer Arithmetic

Pointer arithmetic refers to operations that can be performed on pointers in C, allowing you to navigate through arrays or memory locations by incrementing, decrementing, or subtracting pointers.

Basics of Pointer Arithmetic

  • When you add or subtract an integer n to a pointer, the pointer moves by n elements, not bytes.
  • The size of the element is automatically accounted for, depending on the type the pointer points to.
  • Valid operations: p + n, p - n, p++, p--, p1 - p2 (pointer difference).

Example

#include <stdio.h>

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int *p = arr;  // Points to arr[0]

    printf("p points to value: %d\n", *p);      // 10

    p++;  // Move to next int element
    printf("After p++, p points to: %d\n", *p); // 20

    p += 2;  // Move two elements ahead
    printf("After p += 2, p points to: %d\n", *p); // 40

    int diff = p - arr;  // Pointer difference
    printf("Pointer difference (p - arr): %d\n", diff); // 3

    return 0;
}

Important Notes

  • Pointer arithmetic is only valid within arrays or contiguous memory blocks.
  • Adding or subtracting pointers pointing to unrelated memory is undefined behavior.
  • Pointer arithmetic respects the size of the data type, so p + 1 moves the pointer by sizeof(type) bytes.
Note: Use pointer arithmetic carefully to avoid accessing out-of-bounds memory, which can cause program crashes or security issues.
