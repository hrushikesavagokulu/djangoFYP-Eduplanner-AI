Assertions

In C, assertions are used as a debugging aid to test assumptions made by the program. If an assertion fails, the program will terminate with an error message.

Why Use Assertions?

  • To detect logic errors early during development.
  • To validate function arguments and invariants.
  • To improve code reliability during testing.

How to Use

You must include the <assert.h> header to use the assert() macro. 

#include <assert.h>

int divide(int a, int b) {
  assert(b != 0); // Check divisor is not zero
  return a / b;
}

Output on Failure

If the assertion fails, you'll see a message like: 

Assertion failed: b != 0, file main.c, line 4

Enabling/Disabling Assertions

Assertions are enabled by default. To disable them (e.g., in production), define NDEBUG before including <assert.h>: 

#define NDEBUG
#include <assert.h>
Disabling assertions removes all assert() calls from the compiled code. Be careful not to rely on side effects inside assertions.

Example

#include <stdio.h>
#include <assert.h>

int main() {
  int x = 5;
  int y = 0;

  assert(y != 0); // This will fail
  printf("Result: %d\\n", x / y);

  return 0;
}
Do not use assertions to handle runtime errors (like file I/O or user input). Use them only for programming logic that should never fail.

Best Practices

  • Use assertions to catch bugs early during development.
  • Remove or disable them in release builds using NDEBUG.
  • Never use assert() in place of actual error handling.
