Enums

Enums in C

enum is a user-defined data type in C that consists of integral constants, making your code more readable and maintainable by giving names to sets of related constants.

Basic Syntax

To define an enum, use the keyword enum followed by the name and a list of identifiers (called enumerators):

enum Day { Sunday, Monday, Tuesday, Wednesday, Thursday, Friday, Saturday };

By default, the first enumerator is assigned the integer value 0, and each subsequent enumerator is incremented by 1 automatically:

  • Sunday = 0
  • Monday = 1
  • and so on...

Using Enums

You can declare variables of the enum type like this:

enum Day today;
today = Wednesday;
printf("Day number: %d\n", today);  // Output: Day number: 3

Assigning Custom Values

You can assign specific integer values to enumerators:

enum Month {
    January = 1,
    February,
    March = 5,
    April,
    May
};

In this example:

  • January = 1
  • February = 2 (auto incremented)
  • March = 5
  • April = 6
  • May = 7

Example Program Using Enums

#include <stdio.h>

enum TrafficLight { Red, Yellow, Green };

int main() {
    enum TrafficLight light = Red;

    if (light == Red) {
        printf("Stop!\n");
    } else if (light == Yellow) {
        printf("Ready...\n");
    } else {
        printf("Go!\n");
    }

    return 0;
}

Why Use Enums?

  • Improves code readability by replacing magic numbers with meaningful names.
  • Makes maintenance easier if you need to change the constant values.
  • Groups related constants logically.
Note: Enums are internally represented as integers, so you can perform integer operations on them, but it's better to use them as symbolic names for clarity.
