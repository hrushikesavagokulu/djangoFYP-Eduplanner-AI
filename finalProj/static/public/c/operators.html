Operators

Operators are symbols that perform operations on variables and values in C programming. They form the core of expressions and enable manipulation of data.

Types of Operators in C

  • Arithmetic Operators: Used for basic math operations.
  • Relational Operators: Used to compare two values.
  • Logical Operators: Used to combine conditional statements.
  • Bitwise Operators: Perform bit-level operations.
  • Assignment Operators: Used to assign values.
  • Increment and Decrement Operators: Increase or decrease a value by one.
  • Conditional (Ternary) Operator: Short form of an if-else statement.
  • Other Operators: sizeof, comma operator, pointer operators, etc.

6. Increment and Decrement Operators

7. Conditional (Ternary) Operator

Syntax: condition ? expression_if_true : expression_if_false;

Example Code

#include <stdio.h>

int main() {
    int a = 10, b = 20;

    printf("a + b = %d\n", a + b);
    printf("a == b? %d\n", a == b);
    printf("Logical AND (a < b && b > 0): %d\n", (a < b && b > 0));
    
    int max = (a > b) ? a : b;
    printf("Max of a and b: %d\n", max);

    a++;
    printf("After a++, a = %d\n", a);

    return 0;
}
Note: Operator precedence and associativity determine the order in which parts of an expression are evaluated. Always use parentheses to make your code clear.
