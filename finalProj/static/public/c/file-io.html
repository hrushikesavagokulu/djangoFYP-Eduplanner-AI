File I/O

File input/output (I/O) in C allows you to read data from files and write data to files on your disk. The C standard library provides a set of functions to handle files through FILE pointers.

Basic File Operations

  • fopen() - Open a file
  • fclose() - Close a file
  • fprintf(), fscanf() - Formatted output/input to/from a file
  • fgets(), fputs() - Read/write strings to/from a file
  • fread(), fwrite() - Read/write binary data

Opening a File

Use fopen() with the filename and mode:

  • "r" - Open for reading
  • "w" - Open for writing (creates new or truncates)
  • "a" - Open for appending
  • Adding "b" makes the mode binary (e.g., "rb")

Example: Writing to a File

#include <stdio.h>

int main() {
    FILE *fp = fopen("example.txt", "w");
    if (fp == NULL) {
        perror("Error opening file");
        return 1;
    }
    fprintf(fp, "Hello, file I/O in C!\n");
    fclose(fp);
    return 0;
}

Example: Reading from a File

#include <stdio.h>

int main() {
    char buffer[100];
    FILE *fp = fopen("example.txt", "r");
    if (fp == NULL) {
        perror("Error opening file");
        return 1;
    }
    while (fgets(buffer, sizeof(buffer), fp) != NULL) {
        printf("%s", buffer);
    }
    fclose(fp);
    return 0;
}

Explanation:

  • fopen() opens the file in the specified mode.
  • fprintf() writes formatted text to the file.
  • fgets() reads a line from the file into a buffer.
  • fclose() closes the file and flushes buffers.
  • perror() prints an error message if the file cannot be opened.
Note: Always check the return value of fopen() to ensure the file was opened successfully before performing I/O operations.
