Data Types in C

In C programming, data types specify the type of data that variables can store. They define the size, layout, and range of values that can be held by variables, as well as the operations allowed on them. Understanding data types is fundamental to writing efficient and error-free C programs.

1. Basic Data Types

C provides several built-in primitive data types that store single values. The most commonly used are:

  • int – stores integer numbers (whole numbers without decimals)
  • float – stores single-precision floating-point numbers (decimals)
  • double – stores double-precision floating-point numbers (more precise decimals)
  • char – stores a single character (like 'A', 'z', or '5')
  • void – represents the absence of type, commonly used for functions that return nothing

Example:

int age = 25;
float temperature = 36.5;
double pi = 3.1415926535;
char grade = 'A';
void someFunction();

3. Floating-Point Types

Floating-point types store decimal numbers. C supports two main floating-point types:

  • float — single precision (usually 4 bytes, approx. 6-7 decimal digits of precision)
  • double — double precision (usually 8 bytes, approx. 15-16 decimal digits of precision)
  • long double — extended precision (platform dependent, more precise than double)

Example:

float price = 12.99f;
double distance = 12345.6789012345;
long double preciseValue = 1.234567890123456789L;

Note: The f and L suffixes indicate float and long double literals respectively.

4. Character Types

The char type is used to store single characters. Although it typically stores ASCII characters, it is essentially a small integer type storing numeric values internally.

There are three variants:

  • char — signed or unsigned (implementation-defined)
  • signed char
  • unsigned char

Example:

char letter = 'A';
unsigned char number = 65; // ASCII for 'A'
signed char negativeValue = -50;

5. Void Type

The void type specifies that no value is available. It is mainly used:

  • To indicate a function returns no value
  • To specify generic pointers (e.g., void*)

Example:

void printMessage() {
  printf("Hello, World!\n");
}

void* ptr = malloc(100);

6. Derived Data Types

Derived types are built from basic types:

  • Arrays: Collection of elements of the same type
  • Pointers: Variables that store memory addresses
  • Structures: Collections of variables grouped together
  • Unions: Special data type to store different data types in the same memory location
  • Enums: User-defined set of named integer constants

We will cover these in separate tutorials.

7. Modifiers

Modifiers change the size or sign of basic data types. The commonly used modifiers are:

  • signed — for signed integer types (default for int)
  • unsigned — for unsigned integer types (only positive numbers)
  • short — smaller integer type
  • long — larger integer type
