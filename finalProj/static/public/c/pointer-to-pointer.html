Pointer To Pointer

A pointer to pointer (also called a double pointer) is a pointer variable that stores the address of another pointer. This allows multiple levels of indirection, which can be useful for dynamic memory management, arrays of pointers, or passing pointers by reference to functions.

Declaring a Pointer to Pointer

int **pptr;   // Pointer to a pointer to an int
char **cptr;  // Pointer to a pointer to a char

How Pointer to Pointer Works

  • pptr stores the address of a pointer variable ptr.
  • ptr stores the address of an int variable var.
  • You can access the value of var by dereferencing twice: **pptr.

Example

#include <stdio.h>

int main() {
    int var = 10;
    int *ptr = &var;       // ptr points to var
    int **pptr = &ptr;     // pptr points to ptr

    printf("Value of var: %d\n", var);        // 10
    printf("Value via ptr: %d\n", *ptr);      // 10
    printf("Value via pptr: %d\n", **pptr);   // 10

    // Change var using pptr
    **pptr = 20;
    printf("Updated value of var: %d\n", var); // 20

    return 0;
}

Use Cases for Pointer to Pointer

  • Dynamic memory allocation for multi-dimensional arrays.
  • Passing a pointer by reference to functions so the function can modify the original pointer.
  • Creating arrays of strings (array of char pointers).
Note: Double pointers add complexity and should be used carefully. Always ensure pointers are properly initialized to avoid undefined behavior.
