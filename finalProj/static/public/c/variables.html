Variables in C

Variables are named storage locations in memory that hold data values during the execution of a program. In C, every variable must be declared with a specific data type before it can be used.

Declaring Variables

To declare a variable, specify the data type followed by the variable name:

int age;
float temperature;
char grade;

Initializing Variables

You can assign an initial value to a variable at the time of declaration:

int age = 25;
float temperature = 36.6;
char grade = 'A';

Rules for Naming Variables

  • Names must begin with a letter (A-Z or a-z) or underscore (_).
  • Names can contain letters, digits (0-9), and underscores.
  • Variable names are case-sensitive (e.g., age and Age are different).
  • Names cannot be C keywords (e.g., int, return).

Types of Variables

  • Local variables: Declared inside a function and accessible only within that function.
  • Global variables: Declared outside all functions and accessible from any function in the file.
  • Static variables: Retain their value between function calls.

Example: Using Variables

#include <stdio.h>

int main() {
    int age = 30;
    float height = 5.9;
    char grade = 'B';

    printf("Age: %d\n", age);
    printf("Height: %.1f\n", height);
    printf("Grade: %c\n", grade);

    return 0;
}

Output:

Age: 30
Height: 5.9
Grade: B

Constants vs Variables

Variables can change their values during program execution. If you want to create a value that cannot be changed, use const:

const float PI = 3.14159;

Attempting to modify a constant results in a compilation error.

Summary

  • Variables hold data values and must be declared with a data type.
  • Variable names must follow specific rules and are case-sensitive.
  • Variables can be local, global, or static.
  • Use const to define constants whose values should not change.
