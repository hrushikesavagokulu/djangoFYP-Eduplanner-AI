Functions

Functions are blocks of code designed to perform specific tasks. They help organize your program into reusable pieces, making it easier to read, maintain, and debug.

Function Declaration and Definition

A function has a return type, a name, and optional parameters:

return_type function_name(parameter_list) {
    // function body
}

Example: A Simple Function

int add(int a, int b) {
    return a + b;
}

Calling a Function

To use a function, call it by its name and provide the required arguments:

int result = add(5, 3);
printf("Result: %d\n", result);

Function Components

  • Return type: Specifies the type of value the function returns. Use void if it returns nothing.
  • Function name: Identifies the function.
  • Parameters: Inputs to the function, enclosed in parentheses. Can be empty if no parameters.
  • Function body: Code block executed when the function is called.

Functions with No Return Value

void greet() {
    printf("Hello, world!\n");
}

Calling a Void Function

greet();

Why Use Functions?

  • Break down complex problems into smaller, manageable tasks.
  • Reuse code to avoid duplication.
  • Make programs easier to read and maintain.
  • Facilitate testing and debugging.
Note: Always declare a function before using it, either by defining it above the call or providing a function prototype.
