Void Pointers

A void pointer (also known as a generic pointer) is a special type of pointer in C that can point to any data type. It is declared as void *.

Why Use Void Pointers?

Void pointers are used when you want a pointer to be able to point to different types of data without needing to specify the exact data type. This provides flexibility, especially in functions that need to handle multiple data types.

Key Characteristics

  • Void pointers do not have a type associated with the data they point to.
  • You cannot dereference a void pointer directly because the compiler doesn't know what type it points to.
  • To use the data pointed to by a void pointer, you must first cast it to an appropriate pointer type.

Syntax

void *ptr;

Example: Using Void Pointers

#include <stdio.h>

int main() {
    int num = 42;
    float pi = 3.14;
    
    void *ptr;  // generic pointer
    
    ptr = #  // void pointer points to int
    printf("Value of num: %d\n", *(int *)ptr);  // cast to int* before dereferencing
    
    ptr = π  // void pointer points to float
    printf("Value of pi: %.2f\n", *(float *)ptr);  // cast to float* before dereferencing
    
    return 0;
}

Output:

Value of num: 42
Value of pi: 3.14

Important Points

  • You must always cast a void pointer to the correct pointer type before dereferencing it.
  • Void pointers are commonly used in functions like malloc() which return a generic pointer that can be assigned to any pointer type.
  • Void pointers cannot perform pointer arithmetic directly because the size of the data they point to is unknown.

Example: Using Void Pointer with malloc()

#include <stdio.h>
#include <stdlib.h>

int main() {
    int *arr;
    int n = 5;
    
    // allocate memory for n integers
    arr = (int *)malloc(n * sizeof(int));
    
    if (arr == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }
    
    for (int i = 0; i < n; i++) {
        arr[i] = i * 10;
    }
    
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    
    free(arr);
    return 0;
}

Summary

  • Void pointers provide a way to write flexible and generic code.
  • Always cast void pointers to the appropriate type before using them.
  • Useful in dynamic memory allocation and generic data structures.
