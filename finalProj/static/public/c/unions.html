Unions

Unions in C are a special data type that allows storing different data types in the same memory location. Unlike structs, where each member has its own memory, in a union all members share the same memory area. This means a union can only hold one of its members at a time.

Why Use Unions?

  • To save memory when you know that only one of several variables will be used at a time.
  • To interpret the same memory region in multiple ways, useful in low-level programming.
  • Commonly used in embedded systems, device drivers, and protocol implementations.

Union Syntax

union Data {
    int i;
    float f;
    char str[20];
};

Here, Data can store an int, or a float, or a string of up to 19 characters (plus null terminator), but only one at a time.

Size of a Union

The size of a union is the size of its largest member, because all members share the same memory location.

Example Usage

#include <stdio.h>

union Data {
    int i;
    float f;
    char str[20];
};

int main() {
    union Data data;

    data.i = 10;
    printf("data.i = %d\n", data.i);

    data.f = 220.5;
    printf("data.f = %f\n", data.f);

    // When you assign to data.f, data.i is overwritten
    printf("data.i after assigning to data.f = %d\n", data.i);

    // Assign string to data.str
    snprintf(data.str, sizeof(data.str), "Hello, union!");
    printf("data.str = %s\n", data.str);

    return 0;
}

Note: Since all members share memory, modifying one member affects the others. You should only use the member last assigned.

Accessing Union Members

  • Use the dot operator to access members (e.g., data.i).
  • Be careful about which member you access; accessing a member different from the last written member leads to undefined behavior.

Unions vs Structs

Feature Union Struct
Memory Allocation All members share the same memory Each member has its own memory
Size Size of largest member Sum of all members' sizes (plus padding)
Use Case Store one of many types at a time Store multiple related variables simultaneously

When to Use Unions

  • When memory conservation is critical.
  • When you want to interpret the same memory as different types.
  • In implementing polymorphic data structures.
