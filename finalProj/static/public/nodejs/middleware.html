Express.js Middleware

What is Middleware?

Middleware functions are functions that have access to the request and response objects in an Express.js app, and the next middleware function in the application’s request-response cycle.

They can execute code, make changes to the request/response objects, end the request-response cycle, or call the next middleware.

Types of Middleware

  • Application-level Middleware: Bound to an instance of express() and applies to all routes or specific routes.
  • Router-level Middleware: Bound to an instance of express.Router().
  • Built-in Middleware: Provided by Express.js like express.static() to serve static files.
  • Third-party Middleware: Middleware created by the community, such as body-parser, cors, etc.

Basic Middleware Example

const express = require('express');
const app = express();

// Simple logger middleware
app.use((req, res, next) => {
  console.log(`${req.method} ${req.url}`);
  next(); // Pass control to the next middleware
});

app.get('/', (req, res) => {
  res.send('Hello World!');
});

app.listen(3000, () => console.log('Server running on port 3000'));

Middleware Execution Order

Middleware functions are executed sequentially in the order they are added using app.use() or router methods. If a middleware does not call next(), the request-response cycle ends there.

Error Handling Middleware

Special middleware to handle errors has four arguments: (err, req, res, next). It is used to catch and respond to errors in the app. 

app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).send('Something broke!');
});

Commonly Used Middleware

  • express.json() – Parses incoming JSON requests.
  • express.urlencoded() – Parses URL-encoded bodies.
  • cors() – Enables Cross-Origin Resource Sharing.
  • morgan – HTTP request logger middleware.
  • helmet – Helps secure Express apps by setting various HTTP headers.
