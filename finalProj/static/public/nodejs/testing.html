Testing your Express.js Backend Server

Recently, I have been learning about Node.js and building a backend API server with Express. Express.js allows you to use the MVC pattern (similar to Ruby on Rails) for building RESTful CRUD APIs — a great learning transition.

To verify that the CRUD functionality works properly, it’s essential to test your routes. This guide explains how to test your Express backend API using the Jest testing framework along with the SuperTest library.

Setting Up Jest & SuperTest

To test the Express server, follow these steps:

1. Install Dependencies

npm install --save-dev jest supertest cross-env

2. Configure Testing Scripts

Add the following scripts to your package.json to manage migrations and run tests:


"scripts": {
  "test": "cross-env NODE_ENV=test jest --testTimeout=10000",
  "pretest": "cross-env NODE_ENV=test npm run migrate:reset",
  "migrate:reset": "npx sequelize-cli db:migrate:undo:all && npm run migrate",
  "migrate": "npx sequelize-cli db:migrate && npx sequelize-cli db:seed:all"
}

3. Jest Configuration

Make sure Jest ignores node_modules and uses the Node environment. Add this to package.json:


"jest": {
  "testEnvironment": "node",
  "coveragePathIgnorePatterns": [
    "/node_modules/"
  ]
}

Writing Tests

Create a new file test.js and add the following test code to verify your GET routes:


// test.js

const server = require('../server.js');  // Adjust path to your server file
const supertest = require('supertest');
const request = supertest(server);

describe('User Endpoints', () => {

  it('GET /users should show all users', async () => {
    const res = await request.get('/users');
    expect(res.status).toEqual(200);
    expect(res.type).toEqual(expect.stringContaining('json'));
    expect(res.body).toHaveProperty('users');
  });

  it('GET /users/3 should show a user', async () => {
    const res = await request.get('/users/3');
    expect(res.statusCode).toEqual(200);
    expect(res.body).toHaveProperty('user');
  });

});

Explanation:

  • We import the server and SuperTest.
  • Use request.get() to call endpoints.
  • Check for status code 200, JSON content type, and expected properties in the response body.

Running the Tests

Simply run this command in your terminal:

npm test

If everything is set up correctly, you should see the tests pass successfully.

Conclusion

You now have the basics to test your Express.js backend API routes using Jest and SuperTest. Testing ensures your API behaves as expected and helps catch bugs early.
