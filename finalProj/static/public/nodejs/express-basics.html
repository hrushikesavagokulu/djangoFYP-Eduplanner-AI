Express.js Basics

What is Express.js?

Express.js is a fast, unopinionated, minimalist web framework for Node.js. It simplifies the process of building web applications and APIs by providing a robust set of features for routing, middleware, and more.

Installing Express

You can install Express via npm by running the following command:

npm install express

Creating a Basic Express Server

Here is a simple example of creating a web server that listens on port 3000:

const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hello, Express!');
});

app.listen(3000, () => {
  console.log('Server is running on http://localhost:3000');
});

Routing in Express

Routing defines the endpoints (URIs) that the server responds to, along with the HTTP methods (GET, POST, etc.). 

// Basic GET route
app.get('/about', (req, res) => {
  res.send('About page');
});

// POST route example
app.post('/submit', (req, res) => {
  res.send('Form submitted!');
});

Handling Route Parameters and Query Strings

Express makes it easy to access parameters and query strings in the URL:

// Route parameters
app.get('/users/:userId', (req, res) => {
  const userId = req.params.userId;
  res.send(`User ID is ${userId}`);
});

// Query strings
app.get('/search', (req, res) => {
  const term = req.query.term;
  res.send(`Search term: ${term}`);
});

Serving Static Files

You can serve static files (HTML, CSS, JS, images) using the built-in middleware:

app.use(express.static('public'));

This will serve all files inside the public folder.

Using Middleware in Express

Middleware functions have access to request and response objects and can modify them or end the request-response cycle.

// Simple logger middleware
app.use((req, res, next) => {
  console.log(`${req.method} ${req.url}`);
  next();
});

Error Handling

Express provides a way to handle errors using middleware with four arguments:

app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).send('Something went wrong!');
});
