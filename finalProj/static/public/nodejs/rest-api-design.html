REST API Design in Express.js

REST (Representational State Transfer) is an architectural style for designing networked applications. Express.js makes it easy to build RESTful APIs for your web and mobile apps.

1. What is a RESTful API?

A RESTful API uses standard HTTP methods like GET, POST, PUT, and DELETE to perform CRUD (Create, Read, Update, Delete) operations on resources identified by URIs.

2. RESTful Routes Example

For a resource named books, RESTful endpoints would be:

  • GET /books – Retrieve all books
  • GET /books/:id – Retrieve a specific book
  • POST /books – Create a new book
  • PUT /books/:id – Update an existing book
  • DELETE /books/:id – Delete a book

3. Express.js Code Example


// app.js
const express = require('express');
const app = express();
app.use(express.json());

let books = [
  { id: 1, title: '1984', author: 'George Orwell' },
  { id: 2, title: 'The Hobbit', author: 'J.R.R. Tolkien' }
];

// Get all books
app.get('/books', (req, res) => {
  res.json(books);
});

// Get a single book
app.get('/books/:id', (req, res) => {
  const book = books.find(b => b.id === parseInt(req.params.id));
  if (!book) return res.status(404).send('Book not found');
  res.json(book);
});

// Create a new book
app.post('/books', (req, res) => {
  const newBook = {
    id: books.length + 1,
    title: req.body.title,
    author: req.body.author
  };
  books.push(newBook);
  res.status(201).json(newBook);
});

// Update a book
app.put('/books/:id', (req, res) => {
  const book = books.find(b => b.id === parseInt(req.params.id));
  if (!book) return res.status(404).send('Book not found');
  book.title = req.body.title;
  book.author = req.body.author;
  res.json(book);
});

// Delete a book
app.delete('/books/:id', (req, res) => {
  books = books.filter(b => b.id !== parseInt(req.params.id));
  res.send('Book deleted');
});

app.listen(3000, () => {
  console.log('API server listening on port 3000');
});

4. Best Practices

  • Use nouns for resources (/books), not verbs (/getBooks).
  • Use HTTP status codes properly (e.g., 200, 201, 404, 400).
  • Separate route handlers into controllers for scalability.
  • Validate input data to prevent malformed requests.
  • Use pagination for large datasets (?page=2&limit=10).

5. JSON Format for API Communication

Always send and receive data in JSON format, and set headers accordingly:


Content-Type: application/json
Accept: application/json

6. Testing REST APIs

You can test your REST APIs using tools like:

  • Postman
  • curl (command line)
  • Insomnia

7. Structuring Your API Project

Use a modular structure for large apps:


/routes
  bookRoutes.js
/controllers
  bookController.js
/models
  bookModel.js
app.js

Conclusion

Designing a RESTful API in Express.js is simple and powerful. Following standard conventions and good structure ensures your API is scalable, maintainable, and easy to use.
