Dynamic Pages in Express.js

What Are Dynamic Pages?

Dynamic pages are web pages that generate content on the fly based on user input, database data, or other runtime parameters. Unlike static pages, their content can change without altering the HTML files manually.

Using Template Engines

Express supports several template engines like EJS, Pug, Handlebars, etc., which help generate HTML dynamically.

Example with EJS:

// Install EJS:
// npm install ejs

// In app.js:
const express = require('express');
const app = express();

app.set('view engine', 'ejs');

app.get('/', (req, res) => {
  res.render('index', { title: 'Home Page', message: 'Welcome to dynamic pages!' });
});

app.listen(3000, () => console.log('Server running on port 3000'));

Example views/index.ejs file:

<!DOCTYPE html>
<html>
<head>
  <title><%= title %></title>
</head>
<body>
  <h1><%= message %></h1>
</body>
</html>

Route Parameters for Dynamic URLs

Express lets you capture dynamic parts of the URL using route parameters:

app.get('/user/:id', (req, res) => {
  const userId = req.params.id;
  res.send(`User ID is ${userId}`);
});

Visiting /user/123 will respond with: User ID is 123.

Query Parameters

You can access query string parameters via req.query:

app.get('/search', (req, res) => {
  const term = req.query.term;
  res.send(`Search results for: ${term}`);
});

Visiting /search?term=nodejs will respond with: Search results for: nodejs.

Real-World Use Cases

  • User profiles
  • Product pages
  • Search results
  • Blog posts

Best Practices

  • Sanitize user inputs to avoid security risks.
  • Use caching strategies for frequently requested dynamic pages.
  • Validate route and query parameters.
  • Keep template logic minimal; handle most logic in the controller.
