JavaScript Event Loop

What is the Event Loop?

The Event Loop is a fundamental concept in JavaScript that allows non-blocking asynchronous programming. It handles execution of multiple chunks of your program, coordinating between the call stack, event queue, and callback functions.

The Call Stack

JavaScript is single-threaded, meaning it executes code in a single sequence. The call stack keeps track of function calls in a LIFO (Last In, First Out) order.

Callback Queue (Task Queue)

When asynchronous functions (like timers, I/O, or promises) complete, their callbacks are pushed to the callback queue to be executed when the call stack is empty.

How the Event Loop Works

The event loop constantly checks whether the call stack is empty. If it is, it takes the first callback from the callback queue and pushes it onto the call stack for execution.

Basic Event Loop Example

console.log('Start');

setTimeout(() => {
  console.log('Timeout callback');
}, 0);

console.log('End');

Output:

Start
End
Timeout callback

Although the timeout is set to 0ms, the callback executes last because it is pushed to the callback queue and waits for the call stack to be empty.

Microtasks vs Macrotasks

The event loop differentiates between microtasks (e.g., Promises) and macrotasks (e.g., setTimeout, setInterval). Microtasks have higher priority and run immediately after the current operation before the event loop processes macrotasks. 

console.log('Start');

setTimeout(() => {
  console.log('setTimeout');
}, 0);

Promise.resolve().then(() => {
  console.log('Promise');
});

console.log('End');

Output:

Start
End
Promise
setTimeout

Event Loop Visualization

The event loop cycle looks like this:

  1. Execute code on the call stack.
  2. Process all microtasks (e.g., promises).
  3. Process the next macrotask from the task queue.
  4. Repeat.

Real-World Use Cases

  • Handling user events like clicks and key presses.
  • Making network requests without blocking UI.
  • Scheduling repeated tasks with setInterval.
  • Working with Promises and async/await for asynchronous flows.

Async/Await and the Event Loop

Async functions are syntactic sugar over Promises and microtasks:

async function example() {
  console.log('Async start');
  await Promise.resolve();
  console.log('Async end');
}

example();
console.log('Synchronous log');

Output:

Async start
Synchronous log
Async end

Tips and Best Practices

  • Avoid blocking the event loop with heavy computations.
  • Use asynchronous APIs to keep your app responsive.
  • Be mindful of long-running microtasks which can delay macrotasks.
  • Use tools like setImmediate and process.nextTick (Node.js) for fine control over task scheduling.
