Introduction to WebSockets

WebSockets provide a full-duplex communication channel over a single TCP connection, enabling real-time data transfer between client and server.

Why Use WebSockets?

  • Real-Time Communication: Instant two-way interaction without polling.
  • Low Latency: Persistent connection reduces overhead.
  • Efficient: Less bandwidth usage compared to HTTP requests.
  • Supported by Modern Browsers: Easy to implement on client and server sides.

Basic WebSocket Example

Here is a minimal client-side example of using WebSockets:


// Open a WebSocket connection
const socket = new WebSocket('ws://localhost:8080');

// When connection opens
socket.addEventListener('open', function (event) {
  socket.send('Hello Server!');
});

// Listen for messages
socket.addEventListener('message', function (event) {
  console.log('Message from server ', event.data);
});

How It Fits With Node.js and Express

While Express handles HTTP requests, WebSockets run on a different protocol (ws:// or wss://) but can be integrated with your Node.js server using libraries like ws or socket.io.
