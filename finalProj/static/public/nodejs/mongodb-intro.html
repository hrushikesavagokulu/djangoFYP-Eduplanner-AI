MongoDB Introduction

What is MongoDB?

MongoDB is a popular, open-source NoSQL database designed for scalability, flexibility, and high performance.

Unlike traditional relational databases, MongoDB stores data in JSON-like documents with dynamic schemas, allowing for easier data modeling.

Key Features of MongoDB

  • Document-Oriented Storage: Data is stored in flexible, JSON-like BSON documents.
  • Schema Flexibility: Each document can have a different structure.
  • Scalability: Supports horizontal scaling through sharding.
  • High Performance: Optimized for read/write operations and indexing.
  • Powerful Query Language: Supports rich queries, aggregations, and indexing.

Basic Terminology

  • Database: A container for collections.
  • Collection: A group of MongoDB documents, similar to a table in SQL.
  • Document: A set of key-value pairs stored as BSON (Binary JSON).
  • Field: A key-value pair in a document.
  • Index: Improves query performance.

Installation and Setup

Install MongoDB on your local machine or use a cloud-hosted service like MongoDB Atlas.

For local setup:

sudo apt-get install -y mongodb   # on Ubuntu/Debian
brew tap mongodb/brew               # on macOS
brew install mongodb-community

Start MongoDB server with:

mongod

Basic MongoDB Shell Commands

// Connect to Mongo shell
mongo

// Show databases
show dbs

// Use a database (creates if not exists)
use mydatabase

// Show collections in current database
show collections

// Insert a document
db.users.insertOne({ name: "Alice", age: 30, email: "alice@example.com" })

// Find all documents in a collection
db.users.find()

// Update a document
db.users.updateOne({ name: "Alice" }, { $set: { age: 31 } })

// Delete a document
db.users.deleteOne({ name: "Alice" })

Advantages of Using MongoDB

  • Flexible data model that adapts to evolving application needs.
  • High availability with replica sets.
  • Easy horizontal scaling with sharding.
  • Rich ecosystem and community support.
