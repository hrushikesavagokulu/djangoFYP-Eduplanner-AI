MongoDB Indexes and Aggregation

What are Indexes?

Indexes in MongoDB are special data structures that store a small portion of the collection’s data set in an easy-to-traverse form. They improve the efficiency of search queries by reducing the number of documents MongoDB scans.

Without indexes, MongoDB must perform a collection scan, i.e., scan every document to find those matching the query.

Types of Indexes in MongoDB

  • Single Field Index: Index on a single field (e.g., `{ age: 1 }` for ascending order).
  • Compound Index: Index on multiple fields (e.g., `{ age: 1, name: -1 }`).
  • Multikey Index: Used for indexing array fields.
  • Text Index: Supports text search on string content.
  • Hashed Index: Indexes the hashed value of a field, used mainly for sharding.
  • Geospatial Index: Supports location-based queries.

Creating Indexes

You can create indexes using the createIndex() method in MongoDB shell or driver:

// Create a single field ascending index on "username"
db.users.createIndex({ username: 1 });

// Create a compound index on "lastName" ascending and "age" descending
db.users.createIndex({ lastName: 1, age: -1 });

// Create a text index for full-text search on "description"
db.products.createIndex({ description: "text" });

How MongoDB Uses Indexes

When you run a query, MongoDB checks if it can use any indexes to limit the number of documents it scans. You can verify the index usage by using explain(): 

// Check index usage for a query
db.users.find({ username: "alice" }).explain("executionStats");

MongoDB Aggregation Framework

Aggregation operations process data records and return computed results. It’s similar to SQL’s GROUP BY but far more powerful and flexible.

Aggregation pipelines consist of multiple stages that process documents sequentially.

Common Aggregation Pipeline Stages

  • $match: Filters documents (like a WHERE clause).
  • $group: Groups documents by some expression and computes aggregates.
  • $sort: Sorts documents by a specified field.
  • $project: Reshapes documents, including/excluding fields.
  • $limit: Limits the number of documents.
  • $lookup: Performs left outer join with another collection.

Aggregation Example: Group and Count

Count the number of users in each age group:

db.users.aggregate([
  { $match: { age: { $gte: 18 } } },
  { $group: { _id: "$age", count: { $sum: 1 } } },
  { $sort: { count: -1 } }
]);

Tips for Indexes and Aggregation

  • Create indexes on fields that are frequently queried or used in $match stages for better performance.
  • Compound indexes can support queries filtering on multiple fields.
  • Use explain() to analyze query and aggregation performance.
  • Aggregation pipelines can leverage indexes on the initial $match stage.
  • Avoid unnecessary large data transfers by filtering early in the pipeline.
