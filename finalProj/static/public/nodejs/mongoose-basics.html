Mongoose Basics Guide

What is Mongoose?

Mongoose is an Object Data Modeling (ODM) library for MongoDB and Node.js. It provides a straightforward, schema-based solution to model your application data.

With Mongoose, you can define schemas for your data, enforce validation rules, and interact with MongoDB using a simple, promise-based API.

Installation

To get started with Mongoose, install it via npm:

npm install mongoose

Connecting to MongoDB

First, connect Mongoose to your MongoDB database:

const mongoose = require('mongoose');

mongoose.connect('mongodb://localhost:27017/mydatabase', {
  useNewUrlParser: true,
  useUnifiedTopology: true
}).then(() => {
  console.log('MongoDB connected');
}).catch(err => {
  console.error('Connection error', err);
});

Here, replace mydatabase with your database name.

Defining a Schema

A schema defines the structure of the documents within a collection:

const userSchema = new mongoose.Schema({
  name: String,
  age: Number,
  email: String
});

This schema describes users with a name, age, and email fields.

Creating a Model

Models are constructors compiled from schemas. Use them to create and read documents:

const User = mongoose.model('User', userSchema);

const newUser = new User({
  name: 'Alice',
  age: 30,
  email: 'alice@example.com'
});

Saving Data

Save documents to the database with save():

newUser.save()
  .then(doc => {
    console.log('User saved:', doc);
  })
  .catch(err => {
    console.error('Save error:', err);
  });

Querying Data

Find documents using find or findOne:

User.find({ age: { $gte: 18 } })
  .then(users => {
    console.log('Adult users:', users);
  })
  .catch(err => {
    console.error('Find error:', err);
  });

Updating Documents

Update documents with updateOne, updateMany, or findByIdAndUpdate:

User.findByIdAndUpdate(userId, { age: 31 }, { new: true })
  .then(updatedUser => {
    console.log('Updated user:', updatedUser);
  })
  .catch(err => {
    console.error('Update error:', err);
  });

Deleting Documents

Delete documents with deleteOne, deleteMany, or findByIdAndDelete:

User.findByIdAndDelete(userId)
  .then(() => {
    console.log('User deleted');
  })
  .catch(err => {
    console.error('Delete error:', err);
  });

Summary

Mongoose makes working with MongoDB simple by allowing you to define schemas, models, and validation in your Node.js apps. It supports promises and async/await syntax for clean code.

Next steps include learning advanced features like middleware, population, validation, and transactions.
