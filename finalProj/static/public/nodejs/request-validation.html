Request Validation in Express.js

Request validation ensures that the data received from a client (such as from a form or API call) is correct and secure before it is used in the server-side logic. In Express.js, you can validate request data using built-in checks or third-party libraries.

Why Request Validation Is Important

  • Prevents malformed or incomplete data from entering your application.
  • Helps secure your application by avoiding injection attacks.
  • Improves error handling and feedback to clients.

Validating Requests Manually

You can manually check fields using simple if statements:


app.post('/register', (req, res) => {
  const { username, email } = req.body;
  if (!username || !email) {
    return res.status(400).json({ error: 'Username and email are required.' });
  }
  res.send('Valid input!');
});

Using a Validation Library: express-validator

express-validator is a powerful library for declarative request validation.

Installation

npm install express-validator

Basic Example


const { body, validationResult } = require('express-validator');

app.post('/register',
  [
    body('username').notEmpty().withMessage('Username is required'),
    body('email').isEmail().withMessage('Valid email is required')
  ],
  (req, res) => {
    const errors = validationResult(req);
    if (!errors.isEmpty()) {
      return res.status(400).json({ errors: errors.array() });
    }
    res.send('User registered successfully!');
  });

Custom Validators

You can also create custom validation logic:


body('password').custom(value => {
  if (value.length < 6) {
    throw new Error('Password must be at least 6 characters long');
  }
  return true;
})

Validation in Routes

For larger apps, extract validation logic into reusable middleware:


// validations/userValidation.js
const { body } = require('express-validator');

exports.registerValidation = [
  body('username').notEmpty(),
  body('email').isEmail(),
  body('password').isLength({ min: 6 })
];
  

// In your route
const { registerValidation } = require('./validations/userValidation');

app.post('/register', registerValidation, (req, res) => {
  // Handle errors and logic
});

Best Practices

  • Validate both client-side and server-side.
  • Sanitize input to remove dangerous content.
  • Group validators by route or feature.
  • Use standardized error responses for consistency.

Common Libraries for Validation

  • express-validator – Declarative validation middleware.
  • Joi (via joi or celebrate) – Powerful schema-based validation.
  • yup – Schema builder for runtime value parsing and validation.

Conclusion

Request validation is a fundamental part of building secure and reliable web applications. Use libraries like express-validator or Joi to simplify and standardize validation in your Express projects.
