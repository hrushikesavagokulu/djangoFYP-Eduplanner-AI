Authentication Introduction

What is Authentication?

Authentication is the process of verifying the identity of a user or system. It ensures that users are who they claim to be before accessing protected resources.

Common Authentication Methods

  • Username & Password: The most common method, where users provide credentials to log in.
  • Token-based Authentication: Uses tokens like JWT (JSON Web Tokens) for stateless authentication.
  • OAuth: Allows third-party applications to access user data without exposing credentials.
  • Session-based Authentication: Uses server-stored sessions and cookies.
  • Multi-Factor Authentication (MFA): Adds extra layers like OTPs or biometrics.

Example: Basic Username & Password Authentication

const express = require('express');
const bcrypt = require('bcrypt');
const app = express();

app.use(express.json());

// Simulated user database
const users = [];

app.post('/register', async (req, res) => {
  const { username, password } = req.body;
  const hashedPassword = await bcrypt.hash(password, 10);
  users.push({ username, password: hashedPassword });
  res.status(201).send('User registered');
});

app.post('/login', async (req, res) => {
  const { username, password } = req.body;
  const user = users.find(u => u.username === username);
  if (!user) return res.status(400).send('User not found');

  const isMatch = await bcrypt.compare(password, user.password);
  if (!isMatch) return res.status(401).send('Invalid credentials');

  res.send('Login successful');
});

app.listen(3000, () => console.log('Server started on port 3000'));

Token-Based Authentication with JWT

JSON Web Tokens (JWT) are a popular method for stateless authentication. The server issues a token after successful login, and the client sends this token with subsequent requests to access protected routes. 

const jwt = require('jsonwebtoken');
const secretKey = 'your-secret-key';

// After successful login:
const token = jwt.sign({ username: user.username }, secretKey, { expiresIn: '1h' });

// Middleware to protect routes
function authenticateToken(req, res, next) {
  const authHeader = req.headers['authorization'];
  const token = authHeader && authHeader.split(' ')[1];
  if (!token) return res.sendStatus(401);

  jwt.verify(token, secretKey, (err, user) => {
    if (err) return res.sendStatus(403);
    req.user = user;
    next();
  });
}

// Usage
app.get('/protected', authenticateToken, (req, res) => {
  res.send('Protected content');
});

Session-Based Authentication

Sessions store user information on the server side and use cookies to track users. Express-session is a common middleware to handle sessions. 

const session = require('express-session');

app.use(session({
  secret: 'your-secret-key',
  resave: false,
  saveUninitialized: true,
  cookie: { secure: false } // Set true if using HTTPS
}));

app.post('/login', (req, res) => {
  // After verifying user credentials:
  req.session.userId = user.id;
  res.send('Logged in');
});

app.get('/dashboard', (req, res) => {
  if (!req.session.userId) return res.status(401).send('Not authenticated');
  res.send('Welcome to your dashboard');
});

Authentication Best Practices

  • Always hash passwords before storing.
  • Use HTTPS to protect data in transit.
  • Implement rate limiting to prevent brute-force attacks.
  • Use strong secret keys for JWT and sessions.
  • Invalidate tokens/sessions on logout.
  • Consider adding Multi-Factor Authentication (MFA).
