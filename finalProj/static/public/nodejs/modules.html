JavaScript Modules

What are Modules?

Modules are reusable pieces of code that encapsulate implementation details and expose only what is necessary. They help keep code organized, maintainable, and avoid polluting the global namespace.

Types of Modules

  • ES6 Modules: Use export and import syntax and are supported natively in modern browsers and Node.js.
  • CommonJS Modules: Used primarily in Node.js, use module.exports and require().
  • AMD Modules: Asynchronous module definition, used in browsers with libraries like RequireJS.

ES6 Module Syntax

Exporting

// file: math.js
export function add(a, b) {
  return a + b;
}

export const PI = 3.14159;

Importing

// file: main.js
import { add, PI } from './math.js';

console.log(add(2, 3)); // 5
console.log(PI); // 3.14159

Default Export

// file: logger.js
export default function log(message) {
  console.log(message);
}

// file: app.js
import log from './logger.js';
log('Hello from default export!');

CommonJS Module Syntax (Node.js)

// file: utils.js
function multiply(a, b) {
  return a * b;
}

module.exports = multiply;

// file: index.js
const multiply = require('./utils.js');
console.log(multiply(4, 5)); // 20

Using ES6 Modules in the Browser

To use ES6 modules in the browser, include the type="module" attribute in your script tag: 

<script type="module" src="main.js"></script>

This enables support for import and export statements directly in browser JavaScript.

Benefits of Modules

  • Code reuse and encapsulation
  • Improved maintainability
  • Avoids global namespace pollution
  • Better dependency management
