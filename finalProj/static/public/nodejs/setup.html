Setting Up an Express.js Project

Express.js is a minimal and flexible Node.js web application framework that provides a robust set of features for building web and mobile applications. Below is a step-by-step guide to set up a basic Express.js project.

1. Initialize Your Project

First, create a new folder and initialize a new Node.js project:

mkdir my-express-app
cd my-express-app
npm init -y

2. Install Express

Use npm to install Express:

npm install express

3. Create the Entry Point File

Create a file named app.js or index.js as your server entry point:

// app.js
const express = require('express');
const app = express();

// Define a route
app.get('/', (req, res) => {
  res.send('Hello, Express!');
});

// Start the server
app.listen(3000, () => {
  console.log('Server is running on http://localhost:3000');
});

4. Run Your Server

Start your server with the following command:

node app.js

Now open your browser and go to http://localhost:3000 — you should see "Hello, Express!"

5. Project Structure (Optional Best Practice)

As your project grows, consider the following structure:

my-express-app/
├── public/         # static files (CSS, JS, images)
├── routes/         # route handlers
├── views/          # template files (if using a view engine)
├── app.js          # main server file
├── package.json    # project metadata

6. Useful Development Tools

Install nodemon for automatic server restarts during development:

npm install --save-dev nodemon

Then add a script to package.json:

"scripts": {
  "start": "node app.js",
  "dev": "nodemon app.js"
}

Now run your server with:

npm run dev

7. Additional Packages

  • express-session – for handling sessions
  • body-parser – for parsing POST request bodies (now built-in in Express ≥ 4.16)
  • morgan – for HTTP request logging
  • dotenv – for managing environment variables

Conclusion

You’ve now successfully set up a basic Express.js application. From here, you can build APIs, add routes, connect to databases, render views with template engines, and more.
