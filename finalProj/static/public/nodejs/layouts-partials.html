Layouts and Partials in Express.js

What are Layouts and Partials?

Layouts and partials are concepts used in templating engines to help create reusable, maintainable HTML templates.

  • Layouts: Define the overall page structure (header, footer, navigation) shared across multiple pages.
  • Partials: Smaller reusable snippets of markup (e.g., navbars, footers, sidebars) that can be included in layouts or pages.

Why Use Layouts and Partials?

Using layouts and partials avoids code duplication, makes templates easier to manage, and promotes consistency across your app.

Example: Layout with EJS

Basic layout file views/layout.ejs:

<!DOCTYPE html>
<html lang="en">
<head>
  <title><%= title %></title>
</head>
<body>
  <header>
    <h1>My Website</h1>
    <%- include('partials/navbar') %>
  </header>
  <main>
    <%- body %>
  </main>
  <footer>
    <p>© 2025 My Website</p>
  </footer>
</body>
</html>

In your route, you would render a view and pass the content to the layout like this: 

res.render('page', { title: 'Home', body: '
Welcome to the homepage
' });

Example: Partial with EJS

Partial file views/partials/navbar.ejs:

<nav>
  <ul>
    <li><a href="/">Home</a></li>
    <li><a href="/about">About</a></li>
    <li><a href="/contact">Contact</a></li>
  </ul>
</nav>

Using Layouts and Partials with Other Engines

Other popular templating engines like Handlebars and Pug also support layouts and partials with similar concepts but different syntax.

  • Handlebars: Uses {{> partialName}} for partials and a main layout specified in configuration.
  • Pug: Uses block content and include partial.pug for layout and partials respectively.
