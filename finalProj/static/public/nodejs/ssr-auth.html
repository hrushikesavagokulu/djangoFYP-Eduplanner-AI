SSR Authentication with Express.js

Server-Side Rendering (SSR) authentication refers to protecting server-rendered routes and pages by verifying a user's credentials or session before the HTML content is rendered and sent to the client. This is useful in web applications that use template engines like Pug, EJS, or Handlebars.

Why SSR Authentication?

  • Ensures protected pages are never sent to unauthenticated users
  • Helps prevent unauthorized access to sensitive views
  • Ideal for traditional web apps or hybrid apps using Express and templates

How it Works

The typical flow involves checking user authentication status before rendering the HTML page:

  1. User sends request to access a protected route (e.g. /dashboard)
  2. Middleware checks if user is authenticated
  3. If yes → render HTML with user data
  4. If no → redirect to login page

Basic Example

1. Install Required Modules

npm install express express-session pug

2. Set Up Express with Pug and Sessions

const express = require('express');
const session = require('express-session');
const app = express();

app.set('view engine', 'pug');
app.set('views', './views');

app.use(express.urlencoded({ extended: true }));
app.use(session({
  secret: 'mySecretKey',
  resave: false,
  saveUninitialized: false
}));

3. Authentication Middleware

function isAuthenticated(req, res, next) {
  if (req.session.user) {
    return next();
  }
  res.redirect('/login');
}

4. Routes and Rendering

app.get('/login', (req, res) => {
  res.render('login');
});

app.post('/login', (req, res) => {
  const { username, password } = req.body;
  // Example credentials check
  if (username === 'admin' && password === '1234') {
    req.session.user = username;
    return res.redirect('/dashboard');
  }
  res.render('login', { error: 'Invalid credentials' });
});

app.get('/dashboard', isAuthenticated, (req, res) => {
  res.render('dashboard', { user: req.session.user });
});

app.get('/logout', (req, res) => {
  req.session.destroy(() => {
    res.redirect('/login');
  });
});

Summary

SSR authentication allows Express.js applications to secure their server-rendered views. Using session middleware and a simple login flow, you can protect sensitive content and ensure only authenticated users have access to it.
