Environment Variables in Node.js

What are Environment Variables?

Environment variables are key-value pairs used to configure applications outside of the source code. They are useful to store sensitive information like API keys, database URLs, or configuration settings that vary between environments (development, production, etc.).

Using Environment Variables in Node.js

Node.js exposes environment variables through process.env. For example: 

console.log(process.env.PORT); // Accesses the PORT environment variable

You can set environment variables in your shell before running your Node.js app:

// Linux / macOS
PORT=3000 node app.js

// Windows (PowerShell)
$env:PORT=3000
node app.js

Using dotenv Package

The dotenv package allows you to define environment variables in a .env file at your project root. 

# .env file
PORT=4000
DB_URL=mongodb://localhost/mydb
SECRET_KEY=mysecretkey

Load variables in your app:

require('dotenv').config();

console.log(process.env.PORT); // 4000

Best Practices

  • Never commit your .env file to version control. Use .gitignore to exclude it.
  • Use descriptive variable names in uppercase with underscores, e.g., DB_PASSWORD.
  • Validate required environment variables on app startup.
  • Use different environment files or variables for development, testing, and production.

Validating Environment Variables

Use packages like joi or envalid to validate environment variables:

const envalid = require('envalid');
const { str, port } = envalid;

const env = envalid.cleanEnv(process.env, {
  PORT: port({ default: 3000 }),
  DB_URL: str(),
  SECRET_KEY: str(),
});

Common Environment Variables

  • PORT – The port number your app listens on.
  • NODE_ENV – The environment mode (development, production).
  • DATABASE_URL – Database connection string.
  • API_KEY – Keys for third-party services.
  • SECRET_KEY – Secrets for signing tokens, cookies, etc.
