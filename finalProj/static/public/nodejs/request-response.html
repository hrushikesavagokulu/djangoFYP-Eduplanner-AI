Request and Response in Express

In Express.js, routing is built around the request and response objects. These represent the HTTP request sent by the client and the HTTP response returned by the server.

The req (Request) Object

The req object contains information about the HTTP request, such as:

  • req.params: Route parameters
  • req.query: URL query parameters
  • req.body: Parsed request body (requires middleware like express.json())
  • req.headers: Request headers
  • req.method: HTTP method (e.g., GET, POST)
  • req.url: Full URL path of the request

Example:

app.get('/user/:id', (req, res) => {
  console.log(req.params.id);      // From /user/123 → "123"
  console.log(req.query.search);   // From /user/123?search=abc → "abc"
  res.send('User Page');
});

The res (Response) Object

The res object is used to send a response back to the client. Some common methods are:

  • res.send(): Sends a string or object as a response
  • res.json(): Sends a JSON response
  • res.status(): Sets the HTTP status code
  • res.render(): Renders a template (requires a view engine)
  • res.redirect(): Redirects to a different URL

Example:

app.post('/submit', (req, res) => {
  const name = req.body.name;
  if (!name) {
    return res.status(400).send('Name is required.');
  }
  res.status(200).send(`Hello, ${name}`);
});

Combining Request and Response

app.get('/api/data', (req, res) => {
  const data = { message: 'This is an API response' };
  res.json(data);
});

Middleware and Request/Response

Middleware functions can inspect and modify both req and res before passing control to the next middleware or route. 

app.use((req, res, next) => {
  console.log(`${req.method} ${req.url}`);
  next();
});

Conclusion

Understanding the req and res objects is fundamental to building APIs and web applications with Express. They give you full control over handling client requests and sending proper responses.
