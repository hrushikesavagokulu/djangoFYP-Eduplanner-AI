Passing Data in Express.js

Passing data from the server to the client is a fundamental part of building dynamic web applications. Express.js allows you to pass data to views, APIs, or directly in the response.

Passing Data to Template Views

When rendering HTML with a template engine (like Pug, EJS, or Handlebars), you can pass variables and objects from your route handler to the view.


// Example with Pug
app.get('/profile', (req, res) => {
  const user = { name: 'Alice', age: 25, hobbies: ['Reading', 'Hiking'] };
  res.render('profile', { user: user });
});

In the Pug template profile.pug, you can use the passed user object:


h1 Profile Page
p Name: #{user.name}
p Age: #{user.age}
ul
  each hobby in user.hobbies
    li= hobby

Passing Data via JSON APIs

You can send data as JSON, which is useful for APIs or client-side JavaScript fetching data asynchronously:


app.get('/api/user', (req, res) => {
  res.json({ name: 'Alice', age: 25, hobbies: ['Reading', 'Hiking'] });
});

Passing Data in Query Strings and URL Parameters

Express lets you access parameters from the URL or query strings to dynamically change the response:


app.get('/greet/:name', (req, res) => {
  const name = req.params.name;
  res.send(`Hello, ${name}!`);
});

app.get('/search', (req, res) => {
  const term = req.query.term;
  res.send(`You searched for: ${term}`);
});

Passing Data Between Middleware

Middleware functions can pass data to the next middleware or route handler using the req or res.locals objects:


// Middleware to add a timestamp to request
app.use((req, res, next) => {
  res.locals.requestTime = new Date();
  next();
});

app.get('/', (req, res) => {
  res.render('index', { time: res.locals.requestTime });
});

Using Sessions to Persist Data

Sessions allow you to store user-specific data between requests:


const session = require('express-session');
app.use(session({ secret: 'keyboard cat', resave: false, saveUninitialized: true }));

app.get('/setname', (req, res) => {
  req.session.name = 'Alice';
  res.send('Name stored in session.');
});

app.get('/getname', (req, res) => {
  res.send(`Name in session is: ${req.session.name}`);
});

Best Practices

  • Sanitize data before passing it to views to avoid injection attacks.
  • Keep data passed to templates minimal to improve performance.
  • Use JSON APIs for rich client-side interactivity with frameworks like React or Vue.
  • Use sessions carefully, especially for sensitive data, and secure them properly.

Summary

Passing data effectively in Express.js is key to building dynamic, interactive web applications. Whether you’re rendering templates, responding to API calls, or managing user sessions, Express provides simple, flexible ways to handle data.
