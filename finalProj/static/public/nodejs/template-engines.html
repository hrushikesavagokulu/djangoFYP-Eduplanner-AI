Using Template Engines with Express

A template engine enables you to use static template files in your application. At runtime, the engine replaces variables in the template with actual values, then transforms the template into an HTML file sent to the client. This makes designing dynamic HTML pages easier and cleaner.

Popular Template Engines

The Express application generator uses Pug as the default template engine, but Express also supports others like Handlebars and EJS.

Setting Up Template Engines in Express

  1. Set the views directory: This is where your template files live. Example: 
    app.set('views', './views')
    By default, this is the views folder in your app root.
  2. Set the view engine: Tell Express which template engine to use. Example for Pug: 
    app.set('view engine', 'pug')
  3. Install the template engine npm package. For Pug, run: 
    npm install pug --save

How Rendering Works

Express-compliant template engines export a function named __express(filePath, options, callback) which is called internally by res.render() to render your template.

If a template engine does not follow this convention, you can use the @ladjs/consolidate library which maps popular template engines to Express.

Example Using Pug

Create a Pug template file named index.pug inside your views folder with the following content:

html
  head
    title= title
  body
    h1= message

Create a route in your Express app to render this template:

app.get('/', (req, res) => {
  res.render('index', { title: 'Hey', message: 'Hello there!' })
})

When a request is made to the home page, the index.pug file will be rendered into HTML and sent to the client.

Additional Notes

  • Once the view engine is set (e.g., app.set('view engine', 'pug')), you don't need to specify the file extension when calling res.render().
  • The view engine cache only caches the underlying template file, not the output. So the template is re-rendered on each request even if caching is enabled.
