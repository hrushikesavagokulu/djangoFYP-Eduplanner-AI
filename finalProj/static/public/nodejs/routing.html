Routing in Express.js

Routing in Express.js refers to how your application’s endpoints (URIs) respond to client requests. It’s a core feature of Express used to define how your app handles different HTTP methods and paths.

1. Basic Routing

A route method is derived from an HTTP method and is attached to an Express instance.


// app.js
const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hello, World!');
});

app.listen(3000, () => {
  console.log('Server listening on port 3000');
});

2. Route Methods

Express supports all standard HTTP methods. Common methods include:

  • app.get() – for reading data
  • app.post() – for submitting data
  • app.put() – for updating existing data
  • app.delete() – for removing data

Example:


app.post('/submit', (req, res) => {
  res.send('Form submitted');
});

3. Route Paths

Paths can include strings, string patterns, or regular expressions.


// Matches "/about"
app.get('/about', (req, res) => {
  res.send('About page');
});

// Matches "/ab123cd"
app.get('/ab*cd', (req, res) => {
  res.send('Pattern matched');
});

4. Route Parameters

Parameters in routes can be used to capture values dynamically from the URL.


app.get('/user/:id', (req, res) => {
  res.send(`User ID is ${req.params.id}`);
});

5. Router-Level Middleware

Use express.Router() to create modular route handlers.


// routes/user.js
const express = require('express');
const router = express.Router();

router.get('/', (req, res) => {
  res.send('User list');
});

router.get('/:id', (req, res) => {
  res.send(`User ID: ${req.params.id}`);
});

module.exports = router;

// In main app
const userRoutes = require('./routes/user');
app.use('/users', userRoutes);

6. Chained Route Handlers

You can handle the same path with multiple callbacks (middleware).


app.route('/book')
  .get((req, res) => res.send('Get a book'))
  .post((req, res) => res.send('Add a book'))
  .put((req, res) => res.send('Update a book'));

7. Error Handling for Routes


app.use((req, res) => {
  res.status(404).send('Page not found');
});

Conclusion

Routing is fundamental to any Express application. Using route parameters, middleware, and modular routers allows your app to scale cleanly and efficiently.
