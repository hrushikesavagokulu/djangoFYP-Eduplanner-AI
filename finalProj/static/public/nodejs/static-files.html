Serving Static Files in Express

Express provides a built-in middleware function called express.static to serve static files such as images, CSS files, and JavaScript files.

Function Signature

The signature of the express.static function is: 

express.static(root, [options])

- root: The root directory from which to serve static files.
- options: Optional settings to customize behavior.

Basic Usage

To serve static files from a directory named public, use:

app.use(express.static('public'))

Now you can access files inside public like:

  • http://localhost:3000/images/kitten.jpg
  • http://localhost:3000/css/style.css
  • http://localhost:3000/js/app.js
  • http://localhost:3000/hello.html

Express serves files relative to the static directory, so the directory name (e.g., public) does not appear in the URL.

Using Multiple Static Directories

You can serve multiple directories by calling express.static multiple times:

app.use(express.static('public'))
app.use(express.static('files'))

Express will check these directories in order when looking for files.

Virtual Path Prefix

You can create a virtual prefix for your static files URLs, so the path doesn’t directly map to your filesystem. For example: 

app.use('/static', express.static('public'))

This lets you access files like:

  • http://localhost:3000/static/images/kitten.jpg
  • http://localhost:3000/static/css/style.css

Using Absolute Paths (Recommended)

Since the path in express.static is relative to where you start your Node process, it's safer to use an absolute path. For example: 

const path = require('path')
app.use('/static', express.static(path.join(__dirname, 'public')))

Additional Notes

  • For best performance, consider using a reverse proxy cache in front of your Express app when serving static assets.
  • For detailed options of express.static, refer to the Express static files documentation.
