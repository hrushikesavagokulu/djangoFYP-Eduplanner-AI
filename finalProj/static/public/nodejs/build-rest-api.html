Building REST API with Express.js

What is a REST API?

REST (Representational State Transfer) is an architectural style for designing networked applications. A REST API exposes endpoints that allow clients to perform CRUD operations (Create, Read, Update, Delete) on resources via HTTP methods.

Setting up Express.js

// Initialize a new project and install Express
npm init -y
npm install express

Create app.js:

const express = require('express');
const app = express();

app.use(express.json()); // Parse JSON bodies

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`Server running on port ${PORT}`);
});

Defining RESTful Routes

Common HTTP methods and their typical RESTful use:

  • GET - Retrieve resources
  • POST - Create a new resource
  • PUT / PATCH - Update an existing resource
  • DELETE - Delete a resource

Example: Simple User API

const users = []; // In-memory user store

// Get all users
app.get('/users', (req, res) => {
  res.json(users);
});

// Get user by ID
app.get('/users/:id', (req, res) => {
  const user = users.find(u => u.id === parseInt(req.params.id));
  if (!user) return res.status(404).json({ message: 'User not found' });
  res.json(user);
});

// Create new user
app.post('/users', (req, res) => {
  const user = { id: users.length + 1, name: req.body.name };
  users.push(user);
  res.status(201).json(user);
});

// Update user by ID
app.put('/users/:id', (req, res) => {
  const user = users.find(u => u.id === parseInt(req.params.id));
  if (!user) return res.status(404).json({ message: 'User not found' });
  user.name = req.body.name;
  res.json(user);
});

// Delete user by ID
app.delete('/users/:id', (req, res) => {
  const index = users.findIndex(u => u.id === parseInt(req.params.id));
  if (index === -1) return res.status(404).json({ message: 'User not found' });
  users.splice(index, 1);
  res.status(204).send();
});

Testing Your API

You can test your REST API using tools like:

  • Postman - User-friendly API testing tool
  • curl - Command-line HTTP client
  • Insomnia - Another popular API client

Best Practices

  • Use proper HTTP status codes
  • Validate incoming data
  • Implement error handling middleware
  • Document your API (Swagger, API Blueprint, etc.)
  • Use versioning for your API endpoints
