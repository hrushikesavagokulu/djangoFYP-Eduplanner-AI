JSON Web Tokens (JWT)

What is JWT?

JSON Web Token (JWT) is a compact, URL-safe means of representing claims to be transferred between two parties. It is commonly used for authorization and information exchange in web applications.

A JWT is composed of three parts separated by dots (.): Header, Payload, and Signature.

JWT Structure

  1. Header: Typically consists of the token type (JWT) and the signing algorithm used (e.g., HS256).
  2. Payload: Contains claims, which are statements about an entity (usually the user) and additional data.
  3. Signature: Used to verify that the token was not altered and is generated by signing the encoded header and payload with a secret.

Example JWT format:

xxxxx.yyyyy.zzzzz

How JWT Works

After a user logs in, the server generates a JWT signed with a secret key and sends it to the client. The client stores this token (usually in localStorage or cookies) and sends it with subsequent requests to access protected resources.

The server verifies the token signature to authenticate and authorize the user.

JWT Example Using Node.js and jsonwebtoken

const jwt = require('jsonwebtoken');
const secretKey = 'your-secret-key';

// Creating a token
const token = jwt.sign(
  { userId: 123, role: 'admin' },
  secretKey,
  { expiresIn: '1h' }
);

console.log('Generated Token:', token);

// Verifying a token
try {
  const decoded = jwt.verify(token, secretKey);
  console.log('Decoded Payload:', decoded);
} catch (err) {
  console.error('Token verification failed:', err.message);
}

Security Considerations

  • Keep the secret key confidential and secure.
  • Set appropriate expiration times to limit token lifetime.
  • Use HTTPS to prevent token interception.
  • Validate tokens on every request to protect resources.
  • Consider using refresh tokens for long-term sessions.

Common JWT Use Cases

  • User authentication and session management.
  • Authorization for APIs and microservices.
  • Single sign-on (SSO) implementations.
  • Information exchange between parties securely.
